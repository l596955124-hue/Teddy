## 核心建议

不建议多人共用刘梓寒的 GPT/Codex 账号。

推荐采用：

> 每个人使用自己的 ChatGPT/Codex 账号 + 共同使用 Teddy GitHub 仓库 + 按工作流目录分工协作。

## 原因

1. 共用账号会带来账号安全、会话混乱、责任不可追踪、误操作难定位等问题。
2. OpenAI Codex 手册说明登录凭据会缓存在本机，`auth.json` 需要像密码一样保护，不应分享或提交。
3. GitHub 仓库更适合作为四人共享项目资料的唯一来源。
4. 本项目已经具备 `工作流专区/` 和每日 GitHub 同步规则，适合多人协作。

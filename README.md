# Teddy 商业计划书协作仓库

本仓库用于 Teddy 成人用品即时零售项目的商业计划书、PPT、品牌资产和跨工作流协作。

## 协作入口

新同事或新的 Codex 工作流开始前，优先读取：

1. `项目总控上下文-精简版.md`
2. `跨工作流同步规则.md`
3. `项目协作规则.md`
4. 当前任务相关文件

## 当前主线

当前主线程只维护：

- 商业计划书章节
- 商业计划书 PPT
- 核心商业口径
- 其它专项工作流同步回来的最终结论

## 关键文件

- 商业计划书章节：`01-执行摘要.md` 到 `11-融资计划.md`
- PPT第一版：`输出文件/Teddy商业计划书-A风格-v1.pptx`
- PPT模板：`品牌资产/PPT模板/A风格暖色品牌型/`
- 品牌资产：`品牌资产/`
- 阶段存档：`阶段存档/`

## 注意

本仓库为公开协作仓库，不应提交：

- API Key
- `.env` 文件
- Firecrawl缓存
- `node_modules`
- 临时构建目录 `outputs`

重要结论必须保存为本地文件，不能只保留在聊天记录中。

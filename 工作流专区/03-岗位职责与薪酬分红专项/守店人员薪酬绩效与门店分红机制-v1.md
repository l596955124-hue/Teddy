# Teddy 守店人员薪酬绩效与门店分红机制 v1

生成时间：2026-06-07

## 一、适用范围

本文件用于设计 Teddy 项目前期守店/运营人员的薪酬、绩效、成熟期门店分红机制。

适用对象：

1. 第一个地址的全职执行负责人。
2. 后续每个地址的一人守店/运营负责人。
3. 未来其它岗位可参考本逻辑，只调整底薪、绩效基数和考核权重。

说明：

本机制中的“分红”指项目经营激励或门店经营奖金，不等于工商股权分红，不改变公司股权归属。

## 二、欧阳超前三个月薪酬结构

### 2.1 薪酬结构

| 项目 | 金额 | 说明 |
|------|------|------|
| 底薪+补贴 | 3000 元/月 | 正常出勤、无重大失误时发放 |
| 绩效基数 | 1000 元/月 | 按月度表现计算 |
| 正常完成 | 4000 元/月 | 3000 + 1000 × 1.0 |
| 超额完成 | 4500-5000 元/月 | 绩效系数 1.5-2.0 |
| 月收入区间 | 3000-5000 元/月 | 不含额外阶段奖金、门店分红 |

### 2.2 绩效系数

| 绩效系数 | 绩效金额 | 适用情况 |
|----------|----------|----------|
| 0 | 0 | 严重失职、旷工、造成重大损失 |
| 0.5 | 500 | 工作完成较差，多项延期 |
| 0.8 | 800 | 基本完成，但有明显问题 |
| 1.0 | 1000 | 正常完成岗位工作 |
| 1.2 | 1200 | 完成较好，有主动优化 |
| 1.5 | 1500 | 明显超额，推动开店或运营结果 |
| 2.0 | 2000 | 极好表现，关键节点明显超预期 |

### 2.3 月度考核维度

| 维度 | 分值 | 考核内容 |
|------|------|----------|
| 出勤与守店 | 20 | 按时到岗、覆盖关键营业时段、无无故缺岗 |
| 执行进度 | 25 | 装修、收货、整理、上架、打包、平台任务按节点完成 |
| 库存与商品管理 | 20 | 入库准确、货位清楚、缺货及时反馈、盘点无明显差错 |
| 履约与客服 | 20 | 打包隐私、接单及时、错发漏发少、售后处理稳定 |
| 日报与协作 | 15 | 每日反馈清楚，主动暴露问题，配合团队推进 |

### 2.4 分数对应绩效

| 月度得分 | 系数 | 绩效金额 |
|----------|------|----------|
| 60 分以下 | 0-0.5 | 0-500 |
| 60-74 分 | 0.8 | 800 |
| 75-84 分 | 1.0 | 1000 |
| 85-89 分 | 1.2 | 1200 |
| 90-94 分 | 1.5 | 1500 |
| 95 分以上 | 2.0 | 2000 |

### 2.5 重大加减项

加分项：

| 情况 | 加分 |
|------|------|
| 提前完成关键节点 | +3 至 +5 |
| 主动发现平台、库存、供应商重大问题 | +3 至 +5 |
| 提出有效优化并执行成功 | +3 至 +5 |
| 高峰期主动加班保障履约 | +3 至 +5 |

扣分项：

| 情况 | 扣分 |
|------|------|
| 库存记录不准 | -3 至 -10 |
| 错发漏发造成退款或差评 | -5 至 -15 |
| 未按时提交日报 | -2 至 -5 |
| 未提前反馈卡点导致延期 | -5 至 -10 |
| 严重失职造成明显损失 | 当月绩效降至 0-0.5 |

## 三、成熟期一人守店分红机制

### 3.1 启动门店分红的前提

不建议开店前 1-3 个月就发门店分红。门店分红应在门店相对成熟后启动。

建议满足以下条件后再启动：

1. 单地址连续 2 个月净利润为正。
2. 库存账、现金账、平台账能对得上。
3. 账上至少保留 1 个月房租、工资、补货、风险备用金。
4. 门店履约稳定，无严重错发漏发和平台处罚。
5. 守店人员能够独立完成日常运营、库存、上架、履约、客服和日报。

### 3.2 单地址成熟目标

按当前项目模型，一个地址成熟后承载三家线上店：

| 子品牌店 | 月营业额目标 | 月净利润目标 |
|----------|--------------|--------------|
| TEDDY TOGO 低端店 | 50,000 | 15,000 |
| TEDDY BELLE 高端店 | 30,000 | 10,000 |
| SM/Rainbow 小众店 | 30,000 | 10,000 |
| 单地址合计 | 110,000 | 35,000 |

### 3.3 守店人员收入结构

成熟期守店人员建议采用：

> 底薪 + 绩效 + 门店经营分红/奖金。

建议结构：

| 项目 | 建议 |
|------|------|
| 底薪+补贴 | 3000-4000 元/月 |
| 绩效基数 | 1000-2000 元/月 |
| 门店分红 | 按当月净利润阶梯计算 |
| 阶段奖金 | 开新店、带新人、复制 SOP 时另算 |

说明：

门店分红不是固定工资，只有在门店盈利、账目清楚、现金安全线满足后才发。

### 3.4 门店分红阶梯

建议以“单地址三品牌当月合计净利润”为基数计算。

说明：

一个守店负责人可以负责一个地址下的三个线上品牌店，因此分红不只计算低端店，而是把同一地址下的 TEDDY TOGO、TEDDY BELLE、SM/Rainbow 三家线上店合并核算。

| 当月单地址净利润 | 守店分红比例 | 说明 |
|------------------|--------------|------|
| 15,000 以下 | 0% | 未达基础盈利线，只发工资和绩效 |
| 15,000-24,999 | 5% | 开始盈利，但仍需保现金流 |
| 25,000-34,999 | 8% | 接近成熟，给予明显激励 |
| 35,000-44,999 | 10% | 达到单地址目标 |
| 45,000-54,999 | 12% | 超额完成 |
| 55,000 以上 | 15% 封顶 | 明显超额，但控制分红上限 |

### 3.5 示例测算

| 单地址月净利润 | 守店分红比例 | 守店分红金额 | 若工资绩效为 4000 | 当月总收入 |
|----------------|--------------|--------------|--------------------|------------|
| 15,000 | 5% | 750 | 4000 | 4750 |
| 25,000 | 8% | 2000 | 4000 | 6000 |
| 35,000 | 10% | 3500 | 4000 | 7500 |
| 45,000 | 12% | 5400 | 4000 | 9400 |
| 55,000 | 15% | 8250 | 4000 | 12,250 |

按单地址三品牌成熟目标月净利润 35,000 元计算，守店人员当月可拿：

> 3000-4000 元底薪补贴 + 1000 元左右绩效 + 3500 元门店分红。

即成熟单地址守店负责人月收入约 7500 元左右。

## 四、为什么不建议直接给固定高分红

不建议一开始承诺固定高比例分红，原因：

1. 前期净利润不稳定。
2. 库存、平台、推广和退款会影响真实利润。
3. 项目还需要补货和开新地址。
4. 守店人员的能力要经过验证。
5. 分红过早过高会压缩创始人回本和项目扩张资金。

因此，门店分红必须满足：

1. 先有净利润。
2. 再留安全资金。
3. 再按阶梯发放。

## 五、成熟期门店分红的计算口径

门店分红建议按“当月确认净利润”计算。

当月确认净利润应扣除：

1. 商品进货成本。
2. 平台扣点。
3. 推广费。
4. 房租。
5. 人工工资。
6. 包装物料。
7. 水电网络。
8. 退款、损耗、坏货。
9. 税费和其它实际经营费用。

不建议按营业额分红。营业额高但推广费、退款、库存损耗高时，实际不一定赚钱。

## 六、多人复制时的建议

未来如果一个人负责一个地址，则每个地址单独核算：

| 角色 | 收益方式 |
|------|----------|
| 地址守店负责人 | 底薪 + 绩效 + 本地址门店分红 |
| 区域负责人 | 多地址管理奖金或区域利润提成 |
| 创始人/公司 | 工商股权收益、项目留存、出资回收 |
| 兼职管理岗位 | 项目奖金、数据奖金、虚拟分红权 |

如果一个人同时协助带第二个地址，不建议直接拿第二个地址完整分红，可设置“带店奖金”：

| 场景 | 建议奖金 |
|------|----------|
| 协助新地址开业 | 1000-3000 元阶段奖金 |
| 带新人稳定 30 天 | 1000-3000 元 |
| 新地址第 3 个月达标 | 3000-5000 元 |

## 七、推荐当前执行口径

当前建议先采用以下口径：

1. 前 3 个月欧阳超：3000 元底薪补贴 + 1000 元绩效基数。
2. 正常完成拿 4000 元/月。
3. 超额完成最高拿 5000 元/月。
4. 第 3 个月达标可另发阶段奖金。
5. 门店成熟后启动门店分红。
6. 门店分红按单地址三品牌合计净利润阶梯计算，成熟目标 35,000 元净利润时，守店分红比例为 10%。
7. 门店分红不是工商股权，不影响刘梓寒 100% 工商股权和项目控制权。

## 八、后续待确认

1. 欧阳超前三个月是否按本结构执行。
2. 门店成熟后是否以 35,000 元月净利润作为 10% 分红基准。
3. 守店人员是否同时享受阶段奖金和门店分红。
4. 分红是否按月发，还是按季度结算。
5. 如果当月有大额补货或开新地址投入，门店分红是否延期发放。

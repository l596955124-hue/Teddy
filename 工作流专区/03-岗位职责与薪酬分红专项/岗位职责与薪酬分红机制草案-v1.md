# Teddy 岗位职责与薪酬分红机制草案 v1

> 生成时间：2026-06-07  
> 适用阶段：首店验证期 0-3个月，以及第4个月后是否启动 Rainbow Teddy 的前置判断  
> 文件定位：专项草案，需团队讨论确认后再写入正式协议或商业计划书  

---

## 一、设计原则

Teddy 当前仍处于首店验证期，项目最重要的是跑通现金流和执行闭环，不建议一开始就把股权、分红、岗位工资全部设计得过重。

建议采用：

> 固定薪酬保底 + 绩效奖金驱动 + 阶段项目奖金 + 验证后再谈虚拟股/股权。

核心原则：

1. **先活下来，再分大钱。** 前3个月优先保证现金流、库存和推广缓冲。
2. **谁承担全职执行，谁拿稳定薪酬。** 欧阳超作为全职执行负责人，应有基础薪酬。
3. **谁承担资金和最终风险，谁保留最终控制权。** 刘梓寒作为创始人和资金总控，前期保留控制权。
4. **兼职贡献按结果计奖，不按空头承诺分股。** 汤宇盛、聂思伟可先用项目奖金、绩效和未来虚拟分红权绑定。
5. **股权不急于发，先用“虚拟贡献积分”记录贡献。** 第3个月复盘后再决定是否转为虚拟股、项目分红权或正式股权。
6. **所有分配都要基于净利润和现金流。** 账上没有安全现金储备时，不做大额分红。

## 六、阶段项目奖金机制

建议设置一个“阶段项目奖金池”，只在达成关键节点后发放。

### 6.1 阶段奖金触发条件

| 阶段 | 触发条件 | 奖金池建议 |
|------|----------|------------|
| 阶段1 | 公司/选址/供应商/平台资料准备完成 | 1000-3000元 |
| 阶段2 | TOGO和BELLE完成首批上线并开始试运营 | 2000-5000元 |
| 阶段3 | 第3个月月营收5万且净利润1.5万+ | 5000-10000元 |
| 阶段4 | Rainbow Teddy轻量启动且不影响现金流 | 视现金流另定 |

### 6.2 阶段奖金分配建议

以第3个月达标奖金池为例：

| 成员 | 建议比例 | 分配逻辑 |
|------|----------|----------|
| 刘梓寒 | 20%-30% | 总控、资金、供应链、关键决策 |
| 欧阳超 | 35%-45% | 全职执行、门店和平台履约主力 |
| 汤宇盛 | 10%-15% | 进度管理和节点推进 |
| 聂思伟 | 15%-20% | 数据复盘和利润核算 |

说明：

- 如果刘梓寒选择不拿阶段奖金，可将其比例转入项目备用金或提高欧阳超奖金。
- 如果某成员未完成对应交付物，其奖金比例应下调并进入项目备用金。

## 七、利润分红机制建议

### 7.1 前3个月不建议正式分红

前3个月即使盈利，也建议优先用于：

1. 补货。
2. 推广测试。
3. 包装物料。
4. 现金流缓冲。
5. 第4个月是否启动 Rainbow Teddy 的准备金。

建议前3个月只做：

> 经营净利润记录 + 阶段奖金 + 贡献积分，不做正式利润分红。

### 7.2 第4个月后利润分配建议

当满足以下条件后，再启动月度利润分配：

1. 连续2个月净利润为正。
2. 账上保留不少于3个月固定成本。
3. 库存补货资金充足。
4. 推广费未失控。
5. 经营数据可准确核算。

建议每月净利润分配：

| 用途 | 建议比例 | 说明 |
|------|----------|------|
| 项目留存/补货/扩张 | 50%-60% | 保证现金流和扩张弹性 |
| 团队利润分红池 | 20%-30% | 分给核心团队 |
| 创始人/出资人回收 | 10%-20% | 用于回收前期资金风险 |
| 风险备用金 | 5%-10% | 退款、损耗、突发支出 |

### 7.3 团队利润分红池分配建议

如果设立团队利润分红池，建议按“角色权重 + 当月贡献”分配。

基础建议：

| 成员 | 建议基础比例 | 说明 |
|------|--------------|------|
| 刘梓寒 | 40%-50% | 创始人、资金、供应链、决策风险 |
| 欧阳超 | 25%-35% | 全职执行、运营结果直接责任 |
| 汤宇盛 | 8%-12% | 进度管理和流程推进 |
| 聂思伟 | 10%-15% | 数据复盘、财务跟踪、经营判断 |

可调整因素：

- 如果欧阳超承担夜间履约、客服和平台运营压力明显增加，可提高到35%-40%。
- 如果兼职成员未稳定交付，比例应下调或暂停。
- 如果刘梓寒继续追加资金和承担亏损，创始人/出资人回收比例应保留。

## 八、股权/虚拟股/项目分红权建议

### 8.1 不建议立即发正式股权

原因：

1. 项目还未验证盈利。
2. 各成员投入时间差异明显。
3. 资金主要由创始人承担。
4. 正式股权涉及工商、税务、退出、争议处理，过早设计容易埋雷。

建议：

> 前3个月不发正式股权，只记录贡献积分；第3个月复盘后再决定是否设置虚拟股或项目分红权。

### 8.2 虚拟贡献积分

建议先建立“虚拟贡献积分”，用于记录前3个月贡献，不直接等于股权。

初始建议：

| 成员 | 初始贡献积分 | 说明 |
|------|--------------|------|
| 刘梓寒 | 50 | 创始人、资金、总控、关键风险承担 |
| 欧阳超 | 25 | 全职执行，承担日常运营压力 |
| 汤宇盛 | 10 | 兼职进度管理 |
| 聂思伟 | 15 | 兼职数据和财务复盘 |

每月可根据交付物调整：

| 行为 | 加分建议 |
|------|----------|
| 完成关键交付物 | +1至+3 |
| 解决重大卡点 | +2至+5 |
| 数据/流程沉淀可复用 | +1至+3 |
| 未完成承诺任务 | -1至-3 |
| 严重影响项目进度 | -3至-5 |

### 8.3 第3个月后可选择的三种方案

| 方案 | 适合情况 | 优点 | 风险 |
|------|----------|------|------|
| 继续工资+奖金 | 项目还不稳定 | 简单、风险低 | 绑定力较弱 |
| 虚拟分红权 | 项目盈利但不想动工商股权 | 激励强、灵活 | 需要明确退出规则 |
| 正式股权 | 成员长期全职投入且贡献明确 | 绑定长期利益 | 法务、税务、退出复杂 |

建议优先顺序：

> 工资+奖金 → 虚拟分红权 → 正式股权。

## 九、退出与违约规则建议

### 9.1 退出规则

| 场景 | 建议处理 |
|------|----------|
| 前3个月退出 | 只结清已确认工资/补贴/奖金，不享受后续分红 |
| 未完成交付退出 | 未完成部分奖金取消 |
| 第4个月后退出 | 虚拟分红权按协议逐步失效或保留已成熟部分 |
| 严重违规退出 | 取消未发奖金和未成熟权益 |

### 9.2 权益成熟机制

如果设置虚拟分红权，建议采用成熟期：

| 时间 | 成熟比例 |
|------|----------|
| 第0-3个月 | 只记录贡献，不成熟 |
| 第4-6个月 | 成熟20%-30% |
| 第7-12个月 | 成熟50%-70% |
| 12个月后 | 根据实际协议成熟 |

## 十、推荐当前执行方案

### 10.1 首选方案

前3个月建议采用：

1. 刘梓寒不领固定工资，保留创始人控制权和资金回收权。
2. 欧阳超基础工资4000元/月。
3. 欧阳超可根据上架、履约、库存、达标结果获得500-2000元/月绩效。
4. 汤宇盛、聂思伟前期不设高固定工资，可设置0-500元/月协作补贴。
5. 设置阶段项目奖金池，尤其是第3个月达标后发放。
6. 前3个月不做正式利润分红。
7. 记录虚拟贡献积分，用于第3个月后讨论虚拟分红权。

### 10.2 第3个月复盘后再决定

第3个月复盘时重点看：

| 判断项 | 决策影响 |
|--------|----------|
| 是否达到5万营收 | 决定是否继续当前模式 |
| 是否达到1.5万净利润 | 决定是否启动分红机制 |
| 欧阳超是否承担稳定运营 | 决定是否提高薪酬/分红 |
| 汤宇盛/聂思伟是否稳定交付 | 决定是否给虚拟分红权 |
| 是否启动Rainbow Teddy | 决定是否新增私域/社群岗位 |
| 现金流是否安全 | 决定是否分红或全部留存 |

## 十一、需要团队确认的问题

以下问题需要用户和团队进一步确认：

1. 欧阳超前3个月基础工资是否确定为4000元/月？
2. 汤宇盛、聂思伟是否接受前期以项目奖金和贡献积分为主？
3. 刘梓寒是否全额出资？如果不是，其他成员是否出资？
4. 第3个月达标奖金池愿意设置多少？5000元还是10000元？
5. 第4个月后是否接受“先虚拟分红权、后正式股权”的路径？
6. 如果项目亏损，兼职成员是否仍享受补贴？
7. 如果成员中途退出，贡献积分是否清零或部分保留？

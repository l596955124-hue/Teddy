# Teddy 商品主图与详情页模板规则 v1 审核稿

更新时间：2026-06-10  
适用范围：TEDDY TOGO、TEDDY BELLE、RAINBOW TEDDY 在美团、淘宝闪购、饿了么等平台的商品图文准备。

## 一、总原则

1. 平台商品图优先合规、清晰、真实，不追求过度刺激。
2. 主图优先展示商品外包装、品牌包装或中性产品图，不展示低俗场景。
3. 不使用平台官方 LOGO，不放二维码、微信号、手机号、外链、其他平台导流信息。
4. 商品标题、卖点和图片必须与真实商品一致。
5. 成熟品牌商品保留厂家包装与官方图，避免擅自改包装造成授权或售后风险。
6. 自有/无 LOGO 商品使用 Teddy 自有包装模板，但不得虚假标注品牌授权或功效。

## 二、通用图片结构

| 图序 | 内容 | 制作要求 |
|------|------|----------|
| 主图 1 | 商品外包装正面 | 白底/浅底，主体清楚，不放敏感使用场景 |
| 副图 2 | 背面/规格/厂家信息 | 展示规格、数量、材质、有效期或必要标签 |
| 副图 3 | 套装内容 | 只展示包装、配件、卡片，不展示露骨场景 |
| 详情图 1 | 隐私包装说明 | 外观不展示商品信息，默认隐私包装 |
| 详情图 2 | 售后说明 | 平台售后、拆封说明、可先咨询再选择 |
| 详情图 3 | 品牌风格说明 | 按 TOGO/BELLE/RAINBOW 模板套用 |

## 三、三品牌图文边界

### TEDDY TOGO

定位：低价刚需、快速补给、隐私配送。

允许表达：

- 合规产品包装
- 基础用品外观
- 价格标签
- 快速配送
- 隐私包装
- 深夜补给
- 新手友好

可以更直接，但仍需合规：

- 部分低端品可能出现平台允许范围内的商品外观或包装图。
- 如使用较直白的商品图，应优先使用厂家合规图或包装图，不使用低俗场景图。

不建议表达：

- 真人挑逗图
- 器官暗示
- 低俗文案
- 过度暴露场景
- 夸大功效
- 诱导站外联系

视觉模板：

- 白底/浅橙底
- 橙色角标
- 价格和库存信息清晰
- 商品图要像即时零售刚需品，不像擦边广告图

### TEDDY BELLE

定位：女性高端、卫生、舒适、悦己、礼盒氛围。

允许表达：

- 礼盒
- 丝袜盒
- 服饰吊牌
- 柔软材质
- 卫生舒适
- 女性悦己
- 香氛和包装氛围

边界要求：

- 高端女性用品不能出现太暴露的图片。
- 情趣衣服类优先展示折叠服饰、面料细节、吊牌、礼盒，不用真人暴露模特图。
- 丝袜类优先展示包装盒、材质、颜色、细节，不用过强腿部挑逗图。

不建议表达：

- 太暴露的模特图
- 强性暗示姿势
- 廉价促销感
- 低俗标题
- 明示刺激、挑逗、诱惑等过强词

视觉模板：

- 粉金/奶油白底
- 礼盒和包装质感优先
- 文案强调舒适、卫生、宠爱自己
- 图片要像女性私密护理/高端礼品，而不是低俗成人用品

### RAINBOW TEDDY

定位：多元、尊重、边界、小众探索。

允许表达：

- 彩虹友好
- 边界卡
- 尊重说明
- 紫色礼盒
- 小众氛围
- 私密探索
- 多元友好

边界要求：

- 平台商品图不要直接展示 SM/BDSM 器具或露骨道具。
- 可以用“边界意识卡”“尊重说明卡”“小众风格礼盒”来表达圈层定位。
- 公开平台图应克制；内部资料、私域咨询和用户教育内容可以更明确。

不建议表达：

- 平台图直接展示 SM 器具
- 露骨道具
- 过强圈层暗语
- 暴力、羞辱、非自愿暗示
- 外显敏感身份标签攻击性表达

视觉模板：

- 深紫底或浅底紫色框
- 彩虹细节
- 文案强调多元、尊重、边界
- 商品图以包装、卡片、礼盒、隐私袋为主

## 四、标题与卖点句式

### 通用标题结构

`品牌/系列 + 品类 + 规格/数量 + 使用场景 + 隐私关键词`

示例：

- `TEDDY TOGO 日常补给组合 隐私配送`
- `TEDDY BELLE 柔感丝袜礼盒 舒适亲肤`
- `RAINBOW TEDDY 边界意识卡 多元友好礼盒`

### 慎用词替代表达

| 慎用词 | 替代表达 |
|--------|----------|
| 情趣刺激 | 亲密氛围 |
| 性用品 | 私密护理 / 亲密用品 |
| SM / BDSM | 小众探索 / 边界意识 / 角色氛围 |
| 强烈挑逗 | 氛围感 / 悦己 |
| 诱惑暴露 | 精致剪裁 / 柔软材质 |
| 治疗/改善疾病 | 舒适体验 / 日常护理 |

## 五、上架检查表

| 检查项 | 是否通过 |
|--------|----------|
| 图片不含平台 LOGO、二维码、微信、手机号 |
| 图片不含低俗、露骨、违法违规场景 |
| 商品标题与真实商品一致 |
| 品牌授权或采购来源可追溯 |
| 价格、规格、库存准确 |
| 隐私包装说明已配置 |
| 售后说明已配置 |
| 成年人限定提示已配置 |
| 三品牌风格与商品定位一致 |
| 高端女性用品未使用过度暴露图片 |
| RAINBOW 商品平台图未直接展示高敏感器具 |

## 六、后续模板图生成建议

后续生成商品主图模板前，先给用户审核三套参考方向：

1. TOGO 白底橙标刚需模板。
2. BELLE 粉金礼盒高级模板。
3. RAINBOW 紫色边界卡小众模板。

用户确认后再生成图片，出图后继续遵守“用户确认保存后才落盘”的规则。

# Teddy 平台开店资料准备流程 v1 审核稿

更新时间：2026-06-10  
适用范围：美团闪购、淘宝闪购、饿了么等即时零售平台入驻准备  
状态：用户确认后保存，用于后续开店人按步骤填充资料。

## 一、流程设计原则

1. 先做现在能准备的内容，不等营业执照和门店合同。
2. 明确哪些资料必须等选址、租赁合同、装修或平台后台提交后才能拿到。
3. 把三品牌宣传图、商品图和详情图边界提前定清楚，避免后续上架时反复返工。
4. 所有外显材料优先合规、克制、隐私，不使用真实平台 LOGO 或暗示平台官方背书。

## 三、按阶段准备资料

| 阶段 | 当前能否准备 | 资料内容 | 负责人填充口径 |
|------|--------------|----------|----------------|
| 第0步 开店模型 | 现在能做 | 一个实体店承接 TEDDY TOGO、TEDDY BELLE、RAINBOW TEDDY 三个线上品牌 | 明确线上店数量、实体店职责、是否支持到店自提 |
| 第1步 通用品牌资料 | 现在能做 | LOGO、店铺头像、店铺简介、公告、配送说明、售后说明、隐私包装说明 | 调用 `品牌资产` 和 `文案库` |
| 第2步 三品牌边界 | 现在能做 | 三品牌定位、可用话术、慎用词、宣传图边界 | TOGO 重转化，BELLE 重女性悦己，RAINBOW 重多元边界 |
| 第3步 商品资料表 | 现在能做 | SKU、供应商、品牌、规格、进价、售价、库存、授权状态、平台类目 | 先填候选 SKU，真实上架前再筛选 |
| 第4步 商品图文模板 | 现在能做 | 主图、副图、详情图、隐私包装图、售后说明图 | 按三品牌边界分别套模板 |
| 第5步 履约包装资料 | 现在能做 | 隐私袋、封口贴、售后卡、感谢卡、打包 SOP、骑手取货说明 | 调用包装打样资料包和门店取货区规范 |
| 第6步 选址和合同 | 选址后才能做 | 店铺地址、租赁合同、房东信息、物业允许范围 | 先确认能否注册公司、能否挂门头、是否允许线上零售取货 |
| 第7步 营业执照 | 合同后才能做 | 公司名称、注册地址、法人信息、经营范围 | 必须等地址合同确认后再正式申请 |
| 第8步 门店实景资料 | 装修/布置后才能做 | 门头照、店内照、货架照、打包区照、取货区照、必要时视频 | 按平台要求补拍，保留原图 |
| 第9步 平台提交 | 后台开通后才能做 | 平台账号、资质上传、类目选择、店铺装修、商品上传 | 美团、淘宝闪购、饿了么分平台记录 |
| 第10步 审核补件 | 平台反馈后才能做 | 一镜到底视频、更多实景照、资质说明、品牌授权、整改截图 | 建立补件记录，不要只留聊天记录 |
| 第11步 试营业 | 上架后才能做 | 首批 SKU、价格、库存、订单履约、售后问题、违规风险 | 小批量试跑，先验证审核与转化 |

## 四、营业执照说明

营业执照不要过早乱办，因为注册地址应尽量和租赁合同、平台门店地址、线上公示地址保持一致。

但开店人可以提前准备：

| 提前准备项 | 说明 |
|------------|------|
| 公司名称备选 | 准备 3-5 个名称，避免核名失败 |
| 法人/负责人资料 | 身份证、手机号、实名账户等 |
| 经营范围草案 | 日用百货、个人卫生用品、橡胶制品、成人情趣用品销售等，正式办理前按当地口径核验 |
| 租赁合同要求 | 确认房东是否允许注册公司、是否允许线上零售和取货 |
| 门店用途说明 | 对外可表述为线上即时零售履约、生活护理、隐私取货 |
| 可能涉及资质 | 医疗器械、进口商品、品牌授权、特殊类目按商品实际情况补充 |

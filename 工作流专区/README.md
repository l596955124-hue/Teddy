# Teddy 工作流专区

本目录用于按工作流拆分资料，避免不同专项材料混在根目录。

## 当前工作流

| 文件夹 | 用途 |
|--------|------|
| `01-商业计划书主线程` | 商业计划书、PPT、核心商业口径的主线维护说明 |
| `02-选品与供应商专项` | 低端店、高端店、小众店选品、SKU、供应商、授权资料 |
| `03-岗位职责与薪酬分红专项` | 岗位职责、薪酬、绩效、分红、股权/虚拟股机制 |
| `04-品牌视觉资产专项` | LOGO、VI、包装、门头、线上店铺视觉等后续视觉专项 |

## 固定规则

以后每新开一个工作流，都必须在 `工作流专区/` 下创建独立文件夹。

命名格式：

`编号-工作流名称`

示例：

- `05-平台入驻专项`
- `06-财务测算专项`
- `07-私域运营专项`

每个工作流文件夹至少包含：

- `README.md`
- 该工作流的阶段成果文件
- 必要时创建子文件夹，例如 `资料/`、`表格/`、`截图/`

如果某个专项结论会影响商业计划书或PPT，需要同步更新：

- `项目总控上下文-精简版.md`
- `跨工作流同步规则.md`
- 相关商业计划书章节

# Teddy 库存管理系统专项

本工作流用于单独讨论和沉淀 Teddy 项目的库存管理体系。

## 工作流范围

1. SKU 编码规则
2. 货位编码规则
3. 入库、出库、盘点、调拨流程
4. 安全库存和补货预警
5. 批次、效期、质检和滞销管理
6. 多平台库存同步
7. 是否采用表格、成熟进销存/ERP，或后期自建系统

## 当前建议口径

第 1 个地址不建议自研系统，先使用表格 + 平台后台 + 标准库存流程。

第 2 个地址开始评估成熟进销存/ERP。

第 3 个地址以上再考虑多店库存同步系统。

第 5 个地址以上再评估是否自建系统或定制中台。

## 需要输出的成果

1. `库存管理方案-v1.md`
2. `SKU编码与货位规则-v1.md`
3. `入库出库盘点SOP-v1.md`
4. `库存系统选型对比表-v1.xlsx`
5. `库存管理字段表-v1.xlsx`

## 与其它工作流同步

库存管理结论会影响：

1. 选品与供应商专项
2. 平台入驻专项
3. 公司标准化手册专项
4. 商业计划书主线程的执行流程和风险控制

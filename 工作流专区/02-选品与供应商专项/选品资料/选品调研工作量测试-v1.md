# 选品调研工作量测试 v1

测试时间：2026-06-07

## 一、本轮测试目标

用户希望调研成人用品即时零售线上店的：

- 平台店铺类目数量
- 每个类目卖哪些商品
- 商品原价、折扣价、销量
- 重点竞品：醉清风、河马家、考拉可可、CRLP宝安店
- 供应链进货价：1688 上海醉清风健康科技股份有限公司及其它头部供应链

本轮先做小样本测试，用于估算完整工作时长和上下文/token消耗。

## 四、竞品线上店测试结果

### 1. CRLP宝安店

公开搜索结果不稳定：

- 美团官网网页搜索无法进入具体店铺商品页。
- 淘宝搜索 `CRLP宝安店` 结果不相关。
- 百度能找到 CRLP 成人用品加盟类信息，但不是“CRLP宝安店”的商品表。

判断：

> 若要详细调研 CRLP宝安店，需要从美团/淘宝闪购/饿了么实际消费者端进入店铺，最好提供直接店铺链接、店铺截图，或由用户在 Edge 中打开该店铺页面后再读取。

### 2. 考拉可可

可读取官网：

`https://www.kaolakeke.com/`

官网信息：

- 重庆可拉熊商贸有限公司
- 专注即时零售赛道
- 旗下品牌：考拉可可（成人）、动感日记（成人）、数达蜂（3C数码）、鹤医森（医疗）
- 业务方向：合伙人合作、门店直营、供应链建设

公开搜索还可找到美团投诉页面，证明美团平台存在“考拉可可情趣成人用品店”类商家，但投诉页不能作为完整商品数据来源。

公开搜索可以找到行业新闻和品牌线索，但具体“美团/饿了么/淘宝闪购线上店商品表”需要进入消费者端店铺页。

## 五、完整工作预计耗时

### 简版：先做可用于决策的品类与价格带表

目标：

- 每个竞品店整理 10-20 个主类目
- 每类列 5-10 个代表商品
- 记录原价/折扣价/销量，如果页面能显示
- 1688 对应找 1-3 个进货价参考

预计耗时：

| 任务 | 预计时间 |
|------|----------|
| 1688 醉清风类目与首批商品池 | 1.5-2.5小时 |
| 考拉可可/CRLP/河马家/醉清风竞品入口查找 | 1-2小时 |
| 每个可进入店铺的商品类目表 | 每店45-90分钟 |
| 价格带与毛利初算 | 1-2小时 |
| 输出第一版表格 | 0.5-1小时 |

如果能拿到 3-4 个直接店铺入口，第一版约需 **5-8小时**。

如果需要边搜索边找入口，且平台页面限制较多，约需 **8-12小时**。

### 完整版：接近800-1000个SKU候选池

目标：

- 按 TEDDY TOGO 15-20个类目建立候选池
- 每类30-50个SKU
- 区分核心SKU、普通SKU、长尾SKU
- 关联进货价、参考售价、毛利、平台可上线状态

预计耗时：

| 任务 | 预计时间 |
|------|----------|
| 1688供应链分类抓取 | 4-6小时 |
| 数据清洗/去重/类目归并 | 3-5小时 |
| 竞品售价对照 | 4-8小时 |
| 首批SKU分层建议 | 2-4小时 |
| 输出SKU表 | 2-3小时 |

完整候选池预计 **15-25小时**。

## 六、Token/上下文消耗估算

本轮小样本测试读取了：

- Firecrawl搜索结果
- 1688醉清风首屏约30个商品
- 美团/淘宝闪购官网页面
- 淘宝/百度/考拉可可官网线索

上下文消耗判断：

| 工作方式 | 估算消耗 |
|----------|----------|
| 把网页全文都放进聊天 | 极高，完整项目可能超过150k token，不建议 |
| 分批读取网页，结果写入本地文件，只在聊天汇报结论 | 中等，第一版约40k-80k token |
| 先做类目/价格带简版，再逐步补SKU | 较可控，单轮约8k-20k token |

建议执行方式：

> 不在聊天里展开全部商品原文。每次抓取后直接写入本地 `SKU表/` 或 `选品资料/`，聊天里只汇报结论、缺口和下一步。

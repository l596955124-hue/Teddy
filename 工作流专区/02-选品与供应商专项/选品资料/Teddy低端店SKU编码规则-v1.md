# Teddy 低端店 SKU 编码规则 v1

> 适用范围：TEDDY TOGO 低端店首批 SKU 池、库存管理系统、平台上架表、采购补货表。  
> 建立时间：2026-06-07

## 一、编码目标

后续所有商品不要只用 1688 商品 ID 管理。1688 商品 ID 只能作为“供应商外部货号”，Teddy 内部必须有自己的稳定编码，方便：

- 库存系统导入
- 商品上架
- 采购补货
- 成本和售价管理
- 后续更换供应商但保留内部商品档案

## 二、编码结构

内部 SPU 编码：

`店铺码-供应商码-类目码-四位流水号`

示例：

`TGO-ZQF-MENS-0001`

默认 SKU 编码：

`内部SPU编码-V两位规格号`

示例：

`TGO-ZQF-MENS-0001-V01`

说明：

- 当前 1688 列表层采集只能确认“商品链接级别”，所以先生成 `V01` 默认 SKU。
- 后续详情页增强时，如果同一商品有多个颜色、尺寸、组合规格，则沿用同一个 SPU，拆成 `V01、V02、V03`。
- 不建议把价格、年份、平台名写进 SKU 编码，避免频繁变化。

## 四、字段使用规则

| 字段 | 用途 |
|---|---|
| 内部SPU编码 | Teddy 内部商品档案主编码 |
| 默认SKU编码 | 当前可用于库存系统导入的 SKU 编码 |
| 供应商商品ID | 1688 商品 ID，作为供应商外部货号 |
| 下单链接 | 采购下单追溯 |
| 商品名称 | 采集原始名称，后续平台上架需要另建合规标题 |
| 规格/型号 | 列表层标题提取，后续详情页增强 |
| 单价 | 当前列表采购价参考 |
| 优惠价 | 接口明确返回优惠价时填写，否则留空 |

## 五、后续扩展规则

1. 新增供应商时新增供应商码，不复用 `ZQF`。
2. 新增 Teddy 子品牌时新增店铺码，例如高端店可用 `BEL`，小众店可用 `RBW`。
3. 同一商品更换供应商时，内部 SPU 编码不变，在供应商字段新增备选货源。
4. 同一链接下多规格拆分时，不新建 SPU，只扩展 SKU 尾号。
5. 禁止手工随意改动已入库编码；如确需作废，应新增“状态=作废”，不要删除历史编码。

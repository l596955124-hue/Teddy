# Teddy 加盟模式与区域保护制度 v1

> 更新时间：2026-06-10  
> 当前状态：核心规则已确认  
> 用途：规范 Teddy 总部直营、个人加盟、区域保护、城市保护、新店审批、防内耗机制和区域保护标准支撑件。  
> 适用范围：总部管理层、市场招商团队、区域/城市负责人、直营网点、加盟商、城市合伙人、门店/前置仓负责人。  
> 核心目标：保护单店利润和加盟商赚钱能力，避免过密开店、同品牌内耗和恶性价格竞争。

## 一、FR-001 总部直营与个人加盟双模式原则

Teddy 未来同时保留两种模式：

1. 总部直营模式。
2. 个人加盟模式。

公司核心目标不是短期多收加盟费，而是保护单店利润、区域秩序和加盟商赚钱能力。

### 1.1 总部直营模式

总部直营用于：

1. 打样。
2. 核心城市标杆店。
3. 模型验证。
4. 培训基地。
5. 区域样板。
6. 关键市场控制。

总部直营门店由总部直接投资、经营和管理。

### 1.2 个人加盟模式

个人加盟用于全国复制。

加盟商投资经营，总部提供：

1. 品牌。
2. 货盘。
3. 供应链。
4. 平台经验。
5. 培训。
6. SOP。
7. 数据系统。
8. 运营支持。

### 1.3 底层原则

Teddy 未来采用总部直营和个人加盟双模式。

总部直营用于打样和关键市场控制，个人加盟用于全国复制。

公司必须通过商圈保护、区域保护、城市保护和数据化开店审批，保护单店利润和加盟商赚钱能力，避免过密开店、同品牌内耗和恶性价格竞争。

## 二、FR-002 加盟商前期选址与品牌授权分层

加盟商前期经营的核心不是把门店做大，而是让单店先有足够利润和抗风险能力。

总部鼓励加盟商在前期采用单地址多品牌线上店思路，用一个地址、一个团队、一套库存/打包/履约体系，平摊房租、人员、物料、平台运营和基础管理成本。

但多品牌共享成本不等于总部无条件开放全部品牌。品牌授权必须按照加盟商实力、执行能力、合规表现和经营结果分层开放。

### 2.1 加盟商前期选址建议

前期加盟商优先选择：

1. 房租低的小面积店或前置仓。
2. 配送半径覆盖住宅、公寓、酒店的地址。
3. 能注册、能平台入驻的地址。
4. 骑手取货方便的地址。
5. 物业和房东不敏感的地址。
6. 周边竞品不强或低端同质化明显的地址。

前期加盟商应避开：

1. 学校、幼儿园、青少年培训机构周边。
2. 纯步行街高租金铺面。
3. 居民投诉敏感小区内部。
4. 物业严格、骑手取货受限的写字楼。
5. 竞品价格战严重区域。
6. 无法注册或无法平台入驻的地址。

### 2.2 加盟商品牌授权分层

| 加盟商等级 | 判断条件 | 授权品牌 |
|---|---|---|
| 基础型加盟商 | 资金一般、运营经验少、只能执行基础SOP | 优先授权 TEDDY TOGO |
| 标准型加盟商 | 有稳定资金，能按总部要求做平台运营、库存管理和基础服务 | TEDDY TOGO + 部分 TEDDY BELLE SKU |
| 优质型加盟商 | 有团队、有本地资源、有服务能力、有合规意识，能稳定执行总部标准 | TEDDY TOGO + TEDDY BELLE |
| 城市合伙人型 | 有多店能力、招商/运营资源、区域管理能力，能承担区域责任 | TEDDY TOGO + TEDDY BELLE + RAINBOW TEDDY，按区域保护规则授权 |

### 2.3 品牌可开决策公式

加盟商能否开某个品牌，不能只看地址，也不能只看加盟商意愿，必须同时满足三项条件：

```text
品牌可开 =
地址品牌适配分达标
+ 加盟商授权等级达标
+ 平台/合规风险可控
```

如果地址适合 TEDDY BELLE 或 RAINBOW TEDDY，但加盟商仍属于基础型，原则上先只授权 TEDDY TOGO，等单店经营稳定后再申请升级。

### 2.4 品牌升级条件

加盟商从基础品牌升级到更多品牌授权，必须满足以下条件：

1. 单店经营数据稳定。
2. 平台评分和履约表现达标。
3. 无重大客诉、合规问题或乱价行为。
4. 库存、财务、数据记录符合总部要求。
5. 能接受总部培训、复盘和标准化管理。
6. 具备新增品牌所需的资金、SKU管理和服务能力。

### 2.5 品牌限制与降级

出现以下情况，总部可以暂停新增品牌授权、缩小授权范围或降级为基础品牌：

1. 经营数据长期不达标。
2. 私采高风险商品。
3. 乱价或恶性竞争。
4. 平台违规、资质异常或商品合规问题。
5. 严重客诉或品牌伤害。
6. 拒绝总部数据化管理和复盘。
7. 未经总部同意转让、转包、私下合作。

### 2.6 底层原则

1. 普通加盟商先给低端品牌，把模型跑稳。
2. 高端品牌 TEDDY BELLE 和小众品牌 RAINBOW TEDDY 要看加盟商能力逐步开放。
3. 品牌授权不是一次性给完，而是按经营结果、合规表现、服务质量、资金能力逐步升级。
4. 总部要保护加盟商赚钱能力，也要保护品牌定位和长期口碑。

## 三、FR-003 区域保护机制

Teddy 区域保护采用四层机制：

1. 配送半径保护。
2. 商圈保护。
3. 区域保护。
4. 城市保护。

保护不是无条件独家，而是基于开店能力、经营结果、合规表现和总部标准执行情况的阶段性权益。

### 3.1 配送半径保护

配送半径保护适合即时零售门店。

同一品牌、同一运营模型的门店，在核心配送半径内不重复布局，避免订单互相抢。

建议核心保护半径：

| 城市类型 | 建议核心保护半径 |
|---|---|
| 高密度一线/新一线城市 | 1.5-3 公里 |
| 普通城市主城区 | 3-5 公里 |
| 县城/低密度区域 | 5-8 公里 |

具体半径不写死，需要以平台配送范围、订单密度、人口、商圈和已有门店数据为准。

### 3.2 商圈保护

商圈保护适合单店加盟商。

加盟商签约一个门店后，在合同约定商圈内，总部不再授权同品牌同模型新门店。

不同子品牌需要分别判断是否冲突：

1. TEDDY TOGO 低端即时店。
2. TEDDY BELLE 高端女性店。
3. RAINBOW TEDDY 小众社群店。

同一区域内是否允许不同子品牌并存，需要看是否抢同一批客户。

### 3.3 区域保护

区域保护适合有能力开多店的加盟商。

对表现稳定的加盟商，可给予某区县、片区或多个商圈的优先开发权。

区域保护必须绑定：

1. 开店计划。
2. 开店时间表。
3. 业绩目标。
4. 合规经营。
5. 货款和管理费正常。
6. 总部标准执行。

### 3.4 城市保护

城市保护只给强加盟商或城市合伙人，不能轻易承诺。

城市保护不是永久独家，而是阶段性开发权。

城市保护必须绑定：

1. 开店数量。
2. 时间节点。
3. 业绩目标。
4. 服务标准。
5. 年度复核。

城市保护建议只在以下条件下给：

1. 对方有资金实力。
2. 有本地资源。
3. 能按计划开多店。
4. 能接受总部数据化管理。
5. 能维护品牌和价格体系。
6. 能承担区域团队建设。

### 3.5 保护失效条件

无论哪种保护，只要出现以下情况，总部可以复核、缩小或取消保护：

1. 未按约定时间开店。
2. 门店长期停业或半停业。
3. 连续经营不达标。
4. 拖欠货款、管理费、系统费。
5. 私采高风险商品。
6. 乱价、恶性竞争。
7. 违反品牌、平台、合规标准。
8. 严重客诉或品牌伤害。
9. 拒绝总部数据化管理和复盘。
10. 转让、转包、私下合作未经总部同意。

## 四、FR-004 新店开设审批与防内耗机制

Teddy 新开直营网点或加盟店，必须先通过区域评估，防止过密开店、同品牌抢单、加盟商内耗。

新店审批不是为了限制扩张，而是为了保护单店利润、加盟商信心和 Teddy 品牌长期价值。

底层原则：

> 宁可少开一家赚钱店，不要多开一家内耗店。

### 4.1 新店开设必须评估 8 个维度

| 维度 | 判断重点 |
|---|---|
| 区域人口 | 常住人口、年轻人比例、夜间消费能力 |
| 订单密度 | 美团/饿了么/淘宝闪购同类订单潜力 |
| 竞品数量 | 成人用品店、便利店、无人店、线上即时零售对手 |
| 已有 Teddy 门店 | 是否会影响现有门店订单和利润 |
| 配送半径 | 是否和已有门店高度重叠 |
| 单店利润空间 | 是否足够支撑房租、人工、库存、平台费 |
| 品牌定位冲突 | TOGO、BELLE、RAINBOW 是否抢同一客户 |
| 加盟商能力 | 资金、执行、合规、学习能力、是否接受总部标准 |

### 4.2 新店审批流程

```text
新店申请
↓
区域数据初筛
↓
已有门店影响评估
↓
商圈/配送半径测算
↓
单店盈利模型测算
↓
加盟商/经营主体能力评估
↓
总部或区域审批
↓
进入选址、签约、平台、开业 SOP
```

### 4.3 防内耗红线

以下情况原则上不批准新店：

1. 新店核心配送半径与已有同品牌同模型门店高度重叠。
2. 预计会明显拉低现有门店营业额和净利润。
3. 区域订单密度不足以支撑多店。
4. 加盟商只是想抢现有门店客户。
5. 市场人员为了开单绕过区域保护规则。
6. 新店无法满足总部标准化要求。
7. 现有门店还未稳定盈利，附近又要求开同模型店。
8. 同城价格体系、私域客户、配送边界无法协调。

### 4.4 允许例外的情况

以下情况可以进入专项审批：

1. 不同子品牌定位明显不同，客户群不重叠。
2. 现有门店配送能力不足，订单溢出明显。
3. 大型商圈或高校/社区密集区能支撑多店。
4. 总部直营战略样板店需要布局。
5. 城市合伙人按计划建设区域网络，但必须不损害现有单店利润。

### 4.5 审批原则

Teddy 新开直营网点或加盟店必须经过区域数据、配送半径、现有门店影响、单店盈利模型和经营主体能力评估。

新店不得明显损害已有门店利润，不得制造同品牌内耗。

## 五、FR-005 区域保护标准支撑件

Teddy 的区域保护制度必须配套标准支撑件，否则不能作为正式执行制度。

没有标准支撑的区域保护，不允许招商人员对外承诺。

### 5.1 区域保护判断表

用于判断某个门店应该给哪种保护。

| 判断项 | 标准 |
|---|---|
| 门店类型 | 直营 / 加盟 / 联营 / 托管 |
| 子品牌类型 | TOGO / BELLE / RAINBOW |
| 城市等级 | 一线 / 新一线 / 普通地级市 / 县城 |
| 商圈类型 | 社区 / 写字楼 / 高校 / 夜生活 / 综合商圈 |
| 配送半径 | 平台实际配送范围 |
| 核心保护半径 | 结合城市密度确定 |
| 已有门店距离 | 是否与现有门店重叠 |
| 订单密度 | 是否足够支撑单店盈利 |
| 加盟商能力 | 是否具备执行和合规能力 |
| 保护等级 | 配送半径保护 / 商圈保护 / 区域保护 / 城市保护 |

### 5.2 新店开设审批流程图

```text
新店申请
↓
填写区域保护判断表
↓
系统/区域负责人初筛
↓
是否与已有门店冲突？
├─ 是 → 进入同城门店冲突判断流程
└─ 否
   ↓
单店盈利模型测算
↓
加盟商/经营主体能力评估
↓
审批通过？
├─ 否 → 暂缓/退回/重新选址
└─ 是
   ↓
进入选址签约与开店 SOP
```

### 5.3 同城门店冲突判断流程图

```text
发现新店与已有门店可能重叠
↓
确认是否同品牌同模型
├─ 否 → 判断客户群是否明显不同
│   ├─ 是 → 可进入专项审批
│   └─ 否 → 按冲突处理
└─ 是
   ↓
测算配送半径重叠比例
↓
测算预计对已有门店营业额影响
↓
是否明显影响已有门店利润？
├─ 是 → 原则上不批准
└─ 否
   ↓
是否有订单溢出或市场空白？
├─ 是 → 可进入专项审批
└─ 否 → 暂缓开店
```

### 5.4 区域保护失效复核表

用于判断加盟商或区域合伙人的保护权益是否需要缩小或取消。

| 复核项 | 是否触发 |
|---|---|
| 未按约定时间开店 | 是/否 |
| 门店长期停业或半停业 | 是/否 |
| 连续经营不达标 | 是/否 |
| 拖欠货款、管理费、系统费 | 是/否 |
| 私采高风险商品 | 是/否 |
| 乱价、恶性竞争 | 是/否 |
| 违反品牌、平台、合规标准 | 是/否 |
| 严重客诉或品牌伤害 | 是/否 |
| 拒绝总部数据化管理 | 是/否 |
| 未经同意转让、转包、私下合作 | 是/否 |

### 5.5 招商人员禁止承诺清单

招商人员不能私自承诺：

1. 城市永久独家。
2. 无条件区域保护。
3. 保证不开第二家。
4. 保证回本。
5. 保证利润。
6. 平台一定审核通过。
7. 总部长期补贴亏损。
8. 可以不按总部货盘采购。
9. 可以不按统一价格体系执行。
10. 可以绕开系统和数据化管理。

### 5.6 示例说明

#### 示例 1：同一小区附近是否能开第二家 TOGO？

如果配送半径高度重叠，订单密度不够，原则上不批。

如果现有店订单溢出、配送超时严重，且新店能明显提升履约效率，可专项审批。

#### 示例 2：同一商圈能不能同时开 TOGO 和 BELLE？

如果客户定位不同、商品结构不同、价格带不同，可以评估共存。

如果实际会抢同一批即时订单，应暂缓。

#### 示例 3：城市合伙人要求全城独家怎么办？

不直接承诺永久独家。

只能给阶段性开发权。

必须绑定开店数量、时间节点、业绩目标和年度复核。

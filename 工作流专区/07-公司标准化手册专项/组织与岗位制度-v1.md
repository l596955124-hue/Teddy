# Teddy 组织与岗位制度 v1

> 更新时间：2026-06-09  
> 当前状态：核心规则已确认  
> 用途：规范 Teddy 全国连锁组织架构、岗位清单、岗位任命、权限边界、协作机制和人员变更规则。  
> 适用范围：总部管理层、城市/区域运营层、单地址/门店执行层，以及当前阶段由现有团队兼任岗位的管理。

## 一、O-001 组织架构设计原则

Teddy 采用“总部管理层 + 城市/区域运营层 + 单地址/门店执行层”的三级岗位架构。

当前阶段由现有团队一人兼多岗，后续扩张时按岗位拆分和招聘。

岗位是长期制度单位，人员是阶段任命单位。

一个人可以兼多个岗位，一个岗位未来也可以由不同人员接替。

### 1.1 总部管理层

总部管理层负责战略、品牌、资金、供应链、平台、合规、数据和标准化制度。

总部不成为所有日常事项的审批瓶颈，只把控方向、标准、红线和重大风险。

### 1.2 城市/区域运营层

城市/区域运营层负责未来多城市复制时的城市开店、区域运营、门店督导、培训、业绩跟进和异常处理。

当前阶段先预留，不做过重制度。

### 1.3 单地址/门店执行层

单地址/门店执行层负责一个地址下 TEDDY TOGO、TEDDY BELLE、RAINBOW TEDDY 三个线上店的日常运营、履约、库存、客服和现场管理。

## 二、O-002 基础岗位清单

Teddy 基础岗位按总部管理层、城市/区域运营层、单地址/门店执行层三层设置。

当前阶段只实质启用总部管理层和单地址/门店执行层，城市/区域运营层作为全国连锁预留岗位。

### 2.1 总部管理层岗位

1. 创始人/总经理岗。
2. 项目管理岗。
3. 财务与数据岗。
4. 品牌与内容岗。
5. 商品与供应链岗。
6. 平台运营岗。
7. 合规与资质岗。
8. 标准化与培训岗。

### 2.2 城市/区域运营层岗位

1. 城市负责人岗。
2. 区域运营督导岗。
3. 区域培训岗。
4. 区域仓配/库存协调岗。

当前阶段先预留，不马上招聘。

### 2.3 单地址/门店执行层岗位

1. 门店/前置仓负责人岗。
2. 门店运营岗。
3. 履约打包岗。
4. 库存管理岗。
5. 客服与售后岗。
6. 商品上架岗。
7. 私域引流岗。

前期可以合并，一个守店人员可以兼任门店运营、履约打包、库存管理、客服售后、商品上架和私域引流等岗位。

### 2.4 招商加盟市场团队岗位

招商加盟市场团队不套用普通门店运营岗位制度，单独使用 `招商加盟与市场团队管理制度-v1.md`。

市场团队岗位包括：

1. 总部招商负责人岗。
2. 区域招商经理岗。
3. 城市招商经理岗。
4. 渠道BD岗。
5. 加盟商运营支持岗。

3. 岗位任命表可以变，制度正文不跟着改。

## 四、O-004 分级授权与短审批链原则

Teddy 的组织管理不靠层层审批堆人力，而靠清晰制度、标准流程、岗位权限和结果复盘来管理。

公司采用“总部管理层 + 城市/区域运营层 + 单地址/门店执行层”的三级架构，每一层只审批自己权限范围内的事项。

### 4.1 三级管理边界

| 层级 | 管什么 | 不管什么 |
|---|---|---|
| 总部管理层 | 战略方向、品牌标准、制度标准、财务红线、供应商体系、平台总规则、资质合规、城市扩张、重大合同、核心岗位任命 | 不插手门店日常小额采购、日常排班、常规售后、正常补货 |
| 城市/区域运营层 | 城市开店推进、区域运营、门店督导、人员排班、城市活动、门店业绩、区域库存协调、区域异常处理 | 不擅自改变总部战略、品牌标准、财务红线、核心供应商和重大合同 |
| 单地址/门店执行层 | 门店日常运营、接单履约、库存盘点、补货申请、客服售后、现场物料、日常问题处理 | 不擅自改变品牌定位、商品红线、价格底线、合同条款和超权限支出 |

### 4.2 审批原则

1. 本级权限内，本级负责人审批。
2. 超出本级权限，提交上一级审批。
3. 上一级审批时，抄送再上一级。
4. 总部只管方向、标准、红线和重大风险。
5. 审批链原则上不超过一级。
6. 只有涉及战略、品牌、资质、法律、重大财务、重大合同、重大人员事项时，才进入总部最终审批。

### 4.3 升级触发条件

以下情况必须从当前层级升级到上一级：

1. 超出本级预算或金额权限。
2. 超出标准流程或制度没有覆盖。
3. 涉及品牌定位、VI、对外宣传口径。
4. 涉及证照资质、平台处罚、法律合规风险。
5. 涉及跨城市、跨门店、跨团队资源调配。
6. 涉及供应商更换、品牌授权、采购账期、重大质量问题。
7. 涉及人员任命、薪酬、奖金、分红、退出机制。
8. 涉及合同、租赁、押金、装修、重大支出。
9. 涉及可能造成重大亏损、客户投诉扩散、平台下架或品牌伤害的事项。

### 4.4 管理目标

分级授权与短审批链的目标是让每个岗位知道：

1. 哪些事自己能定。
2. 哪些事要报上一级。
3. 哪些事只需要抄送。
4. 哪些事必须进入总部重大事项审批。

最终形成：

> 清晰标准 + 分级授权 + 一级审批 + 上上级抄送 + 重大事项总部把控。

## 五、O-005 岗位协作机制

Teddy 的岗位协作采用：

> 岗位负责制 + 任务看板 + 短同步 + 周复盘 + 一级审批 + 上上级抄送。

### 5.1 日常协作规则

每个事项必须明确 5 个信息：

| 项目 | 说明 |
|---|---|
| 事项名称 | 要完成什么事 |
| 责任岗位 | 谁对结果负责 |
| 协同岗位 | 谁需要配合 |
| 截止时间 | 什么时候必须完成 |
| 验收标准 | 做到什么程度算完成 |

没有责任岗位、截止时间、验收标准的事项，不进入正式任务。

### 5.2 任务状态规则

所有任务建议只用 5 个状态：

1. 待开始。
2. 进行中。
3. 卡点中。
4. 待审批。
5. 已完成。

### 5.3 每日同步

每日同步不一定开正式会议，可以用群消息或任务表完成。

每个责任岗位只同步 4 件事：

1. 昨天完成了什么。
2. 今天准备做什么。
3. 当前卡点是什么。
4. 需要哪个岗位协助或审批。

原则：只同步事实和卡点，不开空会。

### 5.4 每周复盘

每周由项目管理岗组织一次周复盘，重点看：

1. 本周完成事项。
2. 本周延期事项。
3. 本周新增风险。
4. 下周关键节点。
5. 需要上级审批或跨岗位协同的事项。

周复盘不是批评会，是为了让项目不断往前滚。

### 5.5 跨岗位协作规则

如果一个事项需要多个岗位配合，采用：

> 一个责任岗位牵头，多个协同岗位配合。

不能出现“大家都负责”，因为大家都负责最后就是没人负责。

### 5.6 审批与抄送规则

沿用短审批链：

1. 本级权限内，本级负责人审批。
2. 超出本级权限，提交上一级审批。
3. 上一级审批时，抄送再上一级。
4. 重大事项进入总部最终审批。

### 5.7 卡点升级规则

以下情况必须升级：

1. 超预算。
2. 延期影响关键节点。
3. 涉及平台审核、资质、合同、法律风险。
4. 涉及品牌口径、商品红线、供应商更换。
5. 涉及跨城市、跨门店、跨团队资源。
6. 责任岗位无法独立解决超过 24 小时。

### 5.8 决策记录规则

凡是影响钱、合同、资质、品牌、供应商、平台、团队、招商加盟、门店复制的决策，必须形成决策记录。

口头讨论不算最终制度，写入任务表、会议纪要、制度文件或阶段存档后，才算可执行结论。

## 六、O-006 岗位任命表与人员变更规则

Teddy 所有制度正文按岗位定责，不按人名定责。人员姓名只写入岗位任命表。

### 6.1 岗位任命表字段

岗位任命表必须包含：

| 字段 | 说明 |
|---|---|
| 岗位名称 | 例如门店运营岗、财务与数据岗 |
| 当前任命人员 | 当前由谁担任 |
| 是否兼岗 | 是/否 |
| 上级岗位 | 向哪个岗位汇报 |
| 权限范围 | 该岗位能审批或执行哪些事项 |
| 核心交付物 | 该岗位必须交付什么 |
| 任命开始日期 | 从什么时候开始 |
| 任命状态 | 试任、正式、临时兼任、待替换 |
| 备注 | 特殊说明 |

### 6.2 一人兼多岗规则

当前阶段允许一人兼多岗，但必须满足：

1. 每个岗位都有人负责。
2. 兼岗不能导致关键事项无人跟进。
3. 兼岗人员必须清楚每个岗位的交付物。
4. 后续随着业务增长，优先拆分高频、容易出错、影响用户体验的岗位。

优先拆分顺序建议：

1. 客服与售后岗。
2. 履约打包岗。
3. 库存管理岗。
4. 商品上架岗。
5. 平台运营岗。
6. 市场招商岗。
7. 财务与数据岗。

### 6.3 人员变更规则

人员变更时，不修改制度正文，只更新岗位任命表。

必须更新任命表的情况：

1. 新人入职。
2. 人员离职。
3. 临时兼岗。
4. 岗位职责调整。
5. 城市/门店新增负责人。
6. 市场团队客户归属或门店绑定变化。
7. 岗位权限发生变化。

### 6.4 交接规则

岗位变更必须完成交接，交接至少包括：

1. 当前任务。
2. 未完成事项。
3. 文件资料。
4. 客户、供应商、加盟商联系方式。
5. 平台账号或权限。
6. 库存、财务或数据表。
7. 风险和卡点。
8. 下一步待办。

### 6.5 确认规则

重要岗位任命或变更，必须由上级岗位审批；核心岗位必须由创始人/总经理岗最终确认。

核心岗位包括：

1. 创始人/总经理岗。
2. 总部招商负责人岗。
3. 城市/区域负责人岗。
4. 门店/前置仓负责人岗。
5. 财务与数据岗。
6. 商品与供应链岗。
7. 平台运营岗。
8. 合规与资质岗。

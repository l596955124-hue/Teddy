# Teddy 开店筹备与启动SOP-时间待定版 v1

> 更新时间：2026-06-10  
> 用途：把选址、租赁、注册、平台入驻、供应链、SKU、库存、上架、培训、测试下单、正式开业和开业复盘串成一条可执行流程。  
> 当前状态：总框架已确认，细节待逐条确认。  
> 时间原则：当前不写死具体日期和天数，所有节点先标记为“待定”，等项目正式启动时再统一落到具体时间表。

## 一、制度目的

本SOP用于解决 Teddy 开新店时“事情多、节点散、责任不清、验收不清”的问题。

它不是只服务第一家店的临时清单，而是未来总部直营店、个人加盟店、城市复制和全国连锁开店的基础流程。当前阶段先用第一个地址验证，再逐步升级为全国复制标准。

## 二、适用范围

1. Teddy 总部直营新店。
2. Teddy 单地址三品牌线上店筹备。
3. 后续个人加盟店开业筹备。
4. 后续城市合伙人或区域开店筹备。
5. 与开店有关的选址、注册、平台、供应链、商品、库存、人员、履约、复盘等工作。

## 三、时间管理原则

当前所有时间节点统一使用“待定”，不提前写死具体日期。

正式启动时，再由创始人/总经理岗确认：

1. 项目启动日期。
2. 目标开业日期。
3. 每个阶段的完成期限。
4. 每个关键交付物的验收时间。
5. 是否需要压缩或延长筹备周期。

在未正式启动前，本SOP只确认流程顺序、触发条件、责任岗位、交付结果和验收标准。

## 五、推进原则

开店流程不按日期硬推，而是按交付结果推进。

1. 店址没有通过评估，不能进入租赁签约。
2. 租赁合同风险没有确认，不能支付大额押金或装修款。
3. 主体资质和平台资料没有准备好，不能启动正式入驻。
4. SKU和采购预算没有确认，不能大额进货。
5. 商品档案、货位、库存表没有建立，不能正式上架。
6. 人员没有培训考核通过，不能独立接单履约。
7. 测试下单和异常问题没有关闭，不能正式开业。
8. 开业后没有复盘，不能直接复制到下一家店。

## 九、开店立项与启动条件

### 9.1 启动定义

开店项目不是“看到一个店铺”或“开始聊一个地址”就算正式启动。

只有当创始人/总经理岗确认要启动某一个城市、地址、直营店或加盟店开店项目，并指定项目管理岗负责推进时，才算正式进入开店筹备流程。

### 9.2 启动前必须确认的条件

| 条件 | 标准 |
|---|---|
| 店型方向 | 明确本次开店是直营店、加盟店、单地址三品牌店，还是某一子品牌单店 |
| 品牌组合 | 明确本次涉及 TEDDY TOGO、TEDDY BELLE、RAINBOW TEDDY 中的哪些品牌 |
| 预算边界 | 明确本次开店可使用的预算范围、资金来源和现金流底线 |
| 负责人 | 明确项目管理岗、门店/前置仓负责人岗、财务与数据岗、商品与供应链岗、平台运营岗等关键责任岗位 |
| 经营主体方向 | 明确使用当前经营主体、拟注册新主体，还是加盟商经营主体 |
| 资料归档位置 | 明确本次开店资料归档到哪个工作流或项目文件夹 |

### 9.3 启动责任与权限

| 事项 | 责任岗位 | 权限 |
|---|---|---|
| 是否启动开店项目 | 创始人/总经理岗 | 最终确认 |
| 启动后任务拆解 | 项目管理岗 | 牵头推进 |
| 预算与资金记录 | 财务与数据岗 | 记录、核算、预警 |
| 选址与现场执行 | 城市负责人岗、门店/前置仓负责人岗 | 执行和反馈 |
| 商品与供应链准备 | 商品与供应链岗 | 供应商、SKU、采购计划 |
| 平台入驻与上架 | 平台运营岗、商品上架岗 | 平台资料和商品上线 |
| 合规与资质确认 | 合规与资质岗 | 证照、备案、平台规则核对 |

### 9.4 启动后必须形成的交付物

开店项目正式启动后，必须形成以下交付物：

1. 开店立项确认。
2. 店型定位说明。
3. 品牌组合确认。
4. 预算范围和资金来源说明。
5. 项目责任岗位清单。
6. 开店待办总表。
7. 资料归档位置。
8. 当前待确认风险清单。

### 9.5 暂停启动或重新评估的条件

出现以下情况之一时，开店项目不能正式启动，必须先暂停或重新评估：

1. 资金来源不清。
2. 店型定位不清。
3. 品牌组合不清。
4. 平台规则或资质风险不清。
5. 关键责任岗位缺位。
6. 创始人/总经理岗未确认。
7. 预算边界不清或明显超过现金流安全线。
8. 资料无法归档或责任链不清。

### 9.6 已确认原则

开店启动的核心原则是：不是看到店铺就算启动，而是总部确认这个项目具备推进条件后，才算正式启动。

## 十、店型与品牌组合确认原则

店型与品牌组合不能凭主观感觉决定，必须由“硬性红线 + 城市评分 + 地址评分 + 品牌适配评分”共同判断。

### 10.1 判断流程

```text
候选城市/地址
→ 硬性红线筛查
→ 城市评分
→ 地址评分
→ 品牌适配评分
→ 店型与品牌组合建议
→ 创始人/总经理岗最终确认
```

### 10.2 总体公式

```text
城市总分 =
市场需求分 × 20%
+ 平台成熟度分 × 15%
+ 租金成本分 × 15%
+ 配送基础分 × 10%
+ 竞品空位分 × 15%
+ 合规友好分 × 10%
+ 团队与供应链分 × 10%
+ 扩张价值分 × 5%
```

```text
地址总分 =
需求分 × 25%
+ 配送分 × 15%
+ 租金分 × 15%
+ 竞品分 × 15%
+ 合规分 × 15%
+ 运营分 × 10%
+ 隐私分 × 5%
```

```text
品牌适配分 =
消费人群匹配 × 30%
+ 场景匹配 × 25%
+ 价格带匹配 × 20%
+ 竞品空位 × 15%
+ 隐私与合规 × 10%
```

### 10.3 店型判断

| 店型 | 适用场景 | 品牌组合 |
|---|---|---|
| 单地址三品牌店 | 前期一个地址同时开多家线上店，共享房租、人员、库存、物料 | TEDDY TOGO + TEDDY BELLE + RAINBOW TEDDY |
| 直营标准店 | 总部自己打样、测试模型、做培训基地 | 根据城市和商圈选择1-3个品牌 |
| 加盟标准店 | 加盟商按总部标准开店 | 默认从单品牌或双品牌开始，成熟后扩展 |
| 子品牌单店 | 某个品牌独立定位明显，适合单独运营 | 只开 TOGO / BELLE / RAINBOW 其中一个 |

### 10.4 已确认原则

前期用单地址三品牌提高坪效和人员效率，后期根据城市、商圈、加盟商能力拆成不同店型。  
任何店型和品牌组合都必须有评分依据，不能只靠感觉决定。

详细评分标准见：`选址评分模型-v1.md`。

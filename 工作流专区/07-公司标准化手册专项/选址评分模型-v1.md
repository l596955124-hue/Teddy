# Teddy 选址评分模型 v1

> 更新时间：2026-06-10  
> 用途：用于判断某个城市、商圈、地址是否适合开 Teddy 门店，以及适合开哪种店型、上哪些品牌。  
> 当前状态：底层评分框架、城市评分细化规则、地址评分三段式执行规则和品牌适配评分模型已确认，表格公式待继续细化。  
> 核心原则：选址不能凭感觉，必须先过硬性红线，再用城市评分、地址评分和品牌适配评分共同判断。

## 一、模型目标

本模型解决三个问题：

1. 这个城市值不值得进入。
2. 这个地址能不能开店。
3. 这个地址适合开单地址三品牌店、直营标准店、加盟标准店，还是某个子品牌单店。

未来所有 Teddy 直营、加盟和城市复制项目，都应使用同一套评分逻辑。不同城市可以有特殊性，但特殊性必须转化成评分项、权重或备注，不能只靠主观判断。

## 二、选址判断总流程

```text
候选城市/地址
→ 硬性红线筛查
→ 城市评分
→ 地址评分
→ 品牌适配评分
→ 店型与品牌组合建议
→ 创始人/总经理岗最终确认
```

只要硬性红线未通过，不进入后续评分。

## 三、硬性红线

以下任意一项不通过，原则上暂停，不进入正式谈判或签约。

| 红线 | 标准 |
|---|---|
| 证照红线 | 地址必须能注册或变更营业执照，能用于平台入驻 |
| 租金红线 | 前期首地址房租原则上不超过4000元，或房租/月预估营业额不超过8% |
| 平台红线 | 美团、饿了么、淘宝闪购配送范围和类目审核不能有明显障碍 |
| 未成年人红线 | 避开学校、幼儿园、青少年培训机构等未成年人高密集区域 |
| 投诉红线 | 物业、邻里、门头、骑手取货、快递交接不能有明显投诉风险 |
| 安全红线 | 消防、电路、仓储、夜间进出不能有明显安全隐患 |
| 合同红线 | 房东必须允许经营、仓储、平台入驻、必要门头或物料展示 |

## 四、城市评分模型

城市评分用于判断一个城市是否适合作为 Teddy 的进入城市，满分100分。

城市先决定“值不值得进入”，地址再决定“具体开在哪里”。

### 4.1 城市硬性红线

以下红线不参与打分，先做判断。任意一条不通过，城市暂缓进入。

| 红线 | 暂缓标准 |
|---|---|
| 平台红线 | 美团、饿了么、淘宝闪购成人用品类目无法正常入驻或审核风险极高 |
| 配送红线 | 核心城区夜间配送能力明显不足，无法支撑即时零售 |
| 供应链红线 | 补货时效太慢，常规补货超过可接受周期 |
| 合规红线 | 当地监管、物业、经营地址限制导致成人用品线上店难以稳定经营 |
| 团队红线 | 没有可落地执行人，也没有可靠加盟商或城市负责人候选 |

### 4.2 城市总分公式

```text
城市总分 =
市场需求分 × 20%
+ 平台成熟度分 × 15%
+ 租金成本分 × 15%
+ 配送基础分 × 10%
+ 竞品空位分 × 15%
+ 合规友好分 × 10%
+ 团队与供应链分 × 10%
+ 扩张价值分 × 5%
```

### 4.3 城市评分细项

| 模块 | 权重 | 评分方向 |
|---|---:|---|
| 市场需求分 | 20% | 年轻人多、夜间消费强、酒店/公寓/社区密度高、成人用品即时需求明显 |
| 平台成熟度分 | 15% | 平台同类商家活跃、搜索能看到成交型店铺、平台配送覆盖稳定 |
| 租金成本分 | 15% | 适合前置仓/小店的低租金地址多，房租能压到营业额8%以内 |
| 配送基础分 | 10% | 骑手密度高，3-5公里配送稳定，夜间和雨天履约不容易崩 |
| 竞品空位分 | 15% | 有需求但竞品弱，或竞品低端同质化严重，Teddy有差异化空间 |
| 合规友好分 | 10% | 注册、备案、平台入驻、物业沟通、门头/取货方式风险可控 |
| 团队与供应链分 | 10% | 有人能执行，有补货渠道，有培训落地能力 |
| 扩张价值分 | 5% | 适合做样板城市、区域中心、加盟招商展示城市 |

### 4.4 单项评分规则

每个模块统一按0-100分打分。

| 分数 | 含义 |
|---|---|
| 90-100 | 非常适合，属于优先城市 |
| 80-89 | 适合，可以重点考虑 |
| 70-79 | 可以观察或小规模验证 |
| 60-69 | 风险偏高，只适合特殊机会 |
| 60以下 | 不建议进入 |

### 4.5 城市进入判断

| 城市总分 | 判断 |
|---:|---|
| ≥ 85 | 优先进入，可作为重点城市 |
| 75-84 | 可以进入，但要先做小模型验证 |
| 65-74 | 暂时观察，除非有特别好的地址或加盟商 |
| < 65 | 暂不进入 |

### 4.6 城市特殊性修正

不同城市不能用同一把尺子硬套，需要根据城市类型做修正。修正不是随意加分，而是在评分备注中说明哪个模块应重点关注。

| 城市类型 | 修正重点 |
|---|---|
| 一线/新一线 | 需求强但租金高，重点看租金占比、配送效率、竞品差异化 |
| 二线城市 | 综合性最好，重点看平台成熟度、年轻人密度、可复制性 |
| 三四线城市 | 租金低但需求不一定强，重点看夜间消费、酒店/公寓、平台活跃度 |
| 县城 | 重点看熟人社会隐私风险、配送稳定性、物业投诉风险 |
| 旅游城市 | 酒店和短租需求高，但淡旺季明显，要加季节波动评估 |
| 大学城城市 | 年轻人多，但必须严格避开学校周边未成年人高密集区域 |

### 4.7 城市评估输出

每评估一个城市，必须输出四个结论：

1. 是否建议进入：优先进入 / 小规模验证 / 暂时观察 / 不进入。
2. 建议店型：单地址三品牌 / 单品牌试点 / 加盟优先 / 直营打样。
3. 最大风险：租金、配送、竞品、合规、团队、供应链里哪个最危险。
4. 下一步动作：找地址 / 找加盟商 / 查平台 / 暂停观察。

## 五、地址评分模型

地址评分用于判断具体店铺能不能开，满分100分。

地址评分必须服务效率，不能做成形式主义。执行时不要求所有候选地址都做完整评分，而是采用“三段式评估”：先红线淘汰，再简版排序，只给最有希望的前三个地址做完整评分。

### 5.1 地址评估三段式

| 阶段 | 建议用时 | 目的 | 结果 |
|---|---:|---|---|
| 快速初筛 | 10分钟 | 淘汰明显不能开的地址 | 淘汰 / 进入简评 |
| 简版评分 | 30分钟 | 快速排序，筛出前3个 | 前3进入完整评分 |
| 完整评分 | 1-2小时 | 做截图、数据、谈判依据 | 签约 / 继续谈 / 放弃 |

### 5.2 快速初筛

所有候选地址先做快速初筛。只要发现明显红线，先不评分，直接淘汰或暂停核实。

| 问题 | 判断 |
|---|---|
| 房租是否明显超预算？ | 超4000元且无收入支撑，暂停 |
| 是否能注册或平台入驻？ | 不确定，暂停核实 |
| 是否靠近学校、幼儿园、青少年培训机构？ | 高风险，淘汰 |
| 平台配送是否覆盖核心客群？ | 不覆盖，淘汰 |
| 房东/物业是否允许经营和骑手取货？ | 不允许，淘汰 |
| 是否有消防、电路、潮湿、安全问题？ | 明显问题，淘汰 |
| 周边是否完全没有需求迹象？ | 无需求，淘汰或观察 |

### 5.3 简版评分

初筛通过后，7项用1-5分快速打分。简版评分的目的不是做最终决策，而是在30分钟内排出候选地址优先级。

```text
简版地址分 =
需求/5 × 25
+ 配送/5 × 15
+ 租金/5 × 15
+ 竞品/5 × 15
+ 合规/5 × 15
+ 运营/5 × 10
+ 隐私/5 × 5
```

| 项目 | 权重 | 1分 | 3分 | 5分 |
|---|---:|---|---|---|
| 需求 | 25% | 需求弱 | 有一定需求 | 需求强 |
| 配送 | 15% | 覆盖差 | 基本可用 | 配送稳定 |
| 租金 | 15% | 明显偏高 | 可接受 | 很低 |
| 竞品 | 15% | 价格战严重 | 有竞争但可打 | 竞争可控 |
| 合规 | 15% | 风险大 | 可核实 | 风险低 |
| 运营 | 10% | 难操作 | 可改造 | 顺手高效 |
| 隐私 | 5% | 易尴尬/投诉 | 可补救 | 自然隐蔽 |

| 简版地址分 | 处理 |
|---:|---|
| ≥ 80 | 优先进入完整评分 |
| 70-79 | 备选，可继续了解 |
| 60-69 | 暂放，除非租金特别低 |
| < 60 | 淘汰 |

### 5.4 完整评分

完整评分只对最有希望的前三个地址做，不要求每个候选地址都做重评。

```text
地址总分 =
需求分 × 25%
+ 配送分 × 15%
+ 租金分 × 15%
+ 竞品分 × 15%
+ 合规分 × 15%
+ 运营分 × 10%
+ 隐私分 × 5%
```

| 模块 | 权重 | 必须看什么 |
|---|---:|---|
| 需求 | 25% | 住宅、公寓、酒店、写字楼、夜间消费、平台需求 |
| 配送 | 15% | 平台覆盖、骑手供给、夜间配送、取货便利 |
| 租金 | 15% | 月租、营收占比、押金、转让费、合同灵活度 |
| 竞品 | 15% | 线下/线上竞品数量、价格战、SKU重叠、竞品弱点 |
| 合规 | 15% | 注册、备案、平台审核、物业房东、未成年人敏感点 |
| 运营 | 10% | 面积、仓储、打包区、补货动线、取货动线 |
| 隐私 | 5% | 骑手取货、自提、门头、邻里、包装交接 |

### 5.5 完整评分证据要求

| 模块 | 必须留存的证据 |
|---|---|
| 需求 | 地图截图、周边社区/酒店/公寓记录、平台搜索截图 |
| 配送 | 平台配送范围、骑手取货路径、夜间配送测试 |
| 租金 | 房租、押金、付款方式、同商圈租金对比 |
| 竞品 | 线上店铺截图、SKU价格、评分、活动、线下店数量 |
| 合规 | 房东/物业确认、注册材料、平台入驻要求 |
| 运营 | 平面布局、货架/打包区/取货动线照片 |
| 隐私 | 门头、自提、骑手取货、邻里敏感风险记录 |

### 5.6 地址最终输出

每个完整评分地址，最终只输出6句话，方便创始人/总经理岗决策：

1. 是否建议签约。
2. 建议店型和品牌组合。
3. 最大优势。
4. 最大风险。
5. 签约前必须解决的问题。
6. 创始人/总经理岗最终意见。

### 5.7 地址评分效率原则

地址评分的核心规则是：先红线淘汰，再简版排序，只给前三名做完整评分。

评分不是为了把表填满，而是为了快速淘汰、快速排序、快速决策。

## 六、品牌适配评分模型

品牌适配评分用于判断某个地址适合上哪个 Teddy 子品牌，单品牌满分100分。

品牌适配只回答“地址适不适合某个品牌”，不等于加盟商一定能获得该品牌授权。最终能不能开某个品牌，必须同时满足地址品牌适配分达标、加盟商授权等级达标、平台/合规风险可控。

### 6.1 品牌可开决策公式

```text
品牌可开 =
地址品牌适配分达标
+ 加盟商授权等级达标
+ 平台/合规风险可控
```

如果地址适合 BELLE 或 RAINBOW，但加盟商仍属于基础型，原则上先只授权 TEDDY TOGO，等经营结果、服务能力和合规表现达标后再升级。

### 6.2 品牌适配总公式

```text
品牌适配分 =
消费人群匹配 × 30%
+ 场景匹配 × 25%
+ 价格带匹配 × 20%
+ 竞品空位 × 15%
+ 隐私与合规 × 10%
```

每个地址分别给 TEDDY TOGO、TEDDY BELLE、RAINBOW TEDDY 打分。

### 6.3 三品牌定位

| 品牌 | 定位 | 适合地址 | 授权原则 |
|---|---|---|---|
| TEDDY TOGO | 低端/基础/即时刚需 | 住宅、公寓、酒店、夜间订单强，价格敏感但不极端 | 普通加盟商优先授权 |
| TEDDY BELLE | 高端/女性/礼品/审美 | 中高端社区、白领、公寓酒店、女性消费、礼品场景强 | 标准型以上加盟商逐步开放 |
| RAINBOW TEDDY | 小众/年轻/内容传播 | 年轻人多、潮流消费强、小众接受度高、平台合规可控 | 优质加盟商/城市合伙人谨慎开放 |

### 6.4 品牌适配分判断

| 单品牌适配分 | 判断 |
|---:|---|
| ≥ 85 | 非常适合，可作为主推品牌 |
| 75-84 | 适合上线 |
| 60-74 | 可试运行，控制SKU和库存 |
| < 60 | 不建议上线 |

### 6.5 品牌组合判断

| 评分结果 | 建议 |
|---|---|
| TOGO ≥ 75，BELLE/Rainbow < 60 | 只开 TOGO |
| TOGO ≥ 75，BELLE ≥ 75，Rainbow < 75 | TOGO + BELLE |
| TOGO、BELLE、Rainbow 均 ≥ 75 | 可做单地址三品牌店 |
| Rainbow ≥ 75，但合规/隐私低 | 暂不上 RAINBOW |
| BELLE/Rainbow 高，TOGO 低 | 可做特色店，但不适合普通加盟商前期模型 |

### 6.6 加盟授权等级

| 加盟商等级 | 可授权品牌 |
|---|---|
| 基础型 | TEDDY TOGO |
| 标准型 | TEDDY TOGO + 部分 TEDDY BELLE SKU |
| 优质型 | TEDDY TOGO + TEDDY BELLE |
| 城市合伙人型 | TEDDY TOGO + TEDDY BELLE + RAINBOW TEDDY，按区域保护规则授权 |

### 6.7 总部风控规则

1. TEDDY TOGO 是基础盘，可以作为普通加盟商优先品牌。
2. TEDDY BELLE 不能被打成低价货，必须有定价、图文、包装和服务标准。
3. RAINBOW TEDDY 不能低俗化、擦边化，必须由总部审核内容和SKU。
4. 多品牌共享地址是成本效率策略，不等于全部品牌无条件开放。
5. 品牌授权可以升级，也可以因违规、乱价、投诉、合规问题降级或收回。
6. 普通加盟商先跑通 TEDDY TOGO，经营稳定后再考虑 TEDDY BELLE 或 RAINBOW TEDDY。

### 6.8 品牌适配最终输出

每个地址完成品牌适配后，只输出6个结论：

1. TEDDY TOGO 是否建议上。
2. TEDDY BELLE 是否建议上。
3. RAINBOW TEDDY 是否建议上。
4. 推荐店型：单品牌 / 双品牌 / 三品牌。
5. 加盟商当前授权是否匹配。
6. 需要总部特别审批的品牌。

## 七、开店判断标准

| 结果 | 判断 |
|---|---|
| 硬性红线未过 | 不开，先解决风险 |
| 城市总分 ≥ 80 | 城市优先进入 |
| 城市总分 70-79 | 可以观察或小规模验证 |
| 城市总分 < 70 | 暂不进入，除非有特殊战略原因 |
| 地址总分 ≥ 85 | 优先开，可作为重点地址 |
| 地址总分 75-84 | 可以开，但要明确风险补救 |
| 地址总分 65-74 | 观察地址，不建议马上签约 |
| 地址总分 < 65 | 不开 |
| 单品牌适配 ≥ 75 | 适合上该品牌 |
| 单品牌适配 60-74 | 可小规模试运行 |
| 单品牌适配 < 60 | 不建议上该品牌 |

## 八、店型与品牌组合判断

| 店型 | 触发条件 | 品牌组合建议 |
|---|---|---|
| 单地址三品牌店 | 地址总分高，配送和运营条件强，三个品牌适配分均达到可试运行以上 | TEDDY TOGO + TEDDY BELLE + RAINBOW TEDDY |
| 直营标准店 | 城市有样板价值，总部需要打样、测试模型、做培训基地 | 根据地址适配分选择1-3个品牌 |
| 加盟标准店 | 加盟商能力明确，地址总分达标，区域保护不冲突 | 默认从单品牌或双品牌开始，成熟后扩展 |
| 子品牌单店 | 某一品牌适配分明显高于其他品牌，且该商圈定位清晰 | 只开 TOGO / BELLE / RAINBOW 其中一个 |

## 九、加盟商前期选址建议

前期加盟店优先采用“单地址多品牌线上店”思路，用一个地址、一个团队、一套库存/打包/履约体系，尽量平摊房租、人员、物料、平台运营和基础管理成本。

但“单地址多品牌”不等于所有加盟商一开始都能获得全部品牌授权。具体开放哪些品牌，必须结合加盟商资金实力、执行能力、合规意识、服务能力和历史经营结果分层判断。

### 9.1 前期优先选择的地址

| 优先选择 | 原因 |
|---|---|
| 房租低的小面积店/前置仓 | 降低固定成本，保护加盟商利润 |
| 配送半径覆盖住宅、公寓、酒店 | 保障即时订单基础 |
| 能注册、能平台入驻 | 避免后续被证照或平台审核卡死 |
| 骑手取货方便 | 保证履约效率和平台评分 |
| 物业/房东不敏感 | 降低投诉、退租和经营不稳定风险 |
| 周边竞品不强或低端同质化 | Teddy可以用品牌、包装、履约、私域做差异化 |

### 9.2 前期应避开的地址

| 避开区域 | 原因 |
|---|---|
| 学校、幼儿园、青少年培训机构周边 | 未成年人敏感风险 |
| 纯步行街高租金铺面 | 固定成本过高，不适合前期验证模型 |
| 居民投诉敏感小区内部 | 容易被投诉，影响稳定经营 |
| 物业严格写字楼 | 骑手取货、仓储、物料展示可能受限 |
| 竞品价格战严重区域 | 加盟商利润容易被打穿 |
| 无法注册或无法平台入驻的地址 | 后续无法正常开业 |

### 9.3 加盟商选址底层原则

1. 先让加盟商有利润，再追求门店形象和品牌扩张。
2. 前期不追求大面积门店，不鼓励高租金重装修。
3. 单地址共享成本是效率策略，品牌授权是总部风控策略，两者必须分开判断。
4. 基础型加盟商原则上先从 TEDDY TOGO 开始，经营稳定后再逐步开放 BELLE 或 RAINBOW。
5. 高端品牌和小众品牌必须看加盟商能力，不做无条件开放。

## 十、评分使用要求

1. 所有候选地址必须先做硬性红线筛查。
2. 城市评分、地址评分、品牌适配评分必须保留原始数据来源。
3. 房租、押金、平台覆盖、竞品数量、配送半径、周边人群等信息必须能被复查。
4. 评分结果只作为经营决策依据，不替代创始人/总经理岗最终确认。
5. 如果实际经营结果与评分偏差较大，必须复盘评分权重和判断标准。

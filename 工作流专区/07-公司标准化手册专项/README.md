# Teddy 公司标准化手册专项

本工作流用于单独讨论和沉淀 Teddy 项目的公司标准化管理手册。

## 工作流范围

1. 公司组织规则
2. 岗位职责和协作机制
3. 选址、注册、平台入驻、供应商、上架、履约等标准流程
4. 客服话术、隐私包装、售后退款、差评处理
5. 财务审批、支出记录、数据复盘
6. 合规红线、敏感词、商品图文审核标准
7. 单店复制手册和新地址开店 SOP

## 当前建议口径

公司标准化手册不在岗位薪酬专项里展开，后续单独形成可复制的内部运营手册。

先按第 1 个地址的 30 天开店流程沉淀基础版本，等首店跑通后升级为多地址复制手册。

## 需要输出的成果

1. `Teddy公司标准化手册目录-v1.md`
2. `30天开店SOP-v1.md`
3. `门店日常运营SOP-v1.md`
4. `客服与售后SOP-v1.md`
5. `商品图文合规标准-v1.md`
6. `单店复制手册-v1.md`

## 与其它工作流同步

公司标准化手册需要吸收以下工作流成果：

1. 岗位职责与薪酬分红专项
2. 选品与供应商专项
3. 平台入驻专项
4. 库存管理系统专项
5. 品牌视觉资产专项

# 商业计划书主线程

本工作流只维护 Teddy 创业项目的商业计划书、PPT和核心商业口径。

## 主要文件仍保留在项目根目录

商业计划书主文件放在根目录，便于 GitHub 和同事进入项目后直接查看：

- `01-执行摘要.md` 到 `11-融资计划.md`
- `PPT大纲-v1.md`
- `PPT图表数据表.md`
- `输出文件/`
- `品牌资产/PPT模板/`

## 本工作流职责

- 维护商业计划书章节
- 维护PPT和模板
- 接收其它专项的最终结论
- 统一核心数字口径
- 更新 GitHub 协作和跨工作流规则

## 不在本工作流长时间展开

- SKU逐项选品
- 供应商逐项谈判
- 薪酬分红细节
- 平台后台入驻操作
- LOGO逐图修图

# LOGO与VI设计工作流

> 文档版本：v1.0
> 更新日期：2026-06-06
> 适用范围：Teddy 主品牌、TEDDY TOGO、TEDDY BELLE、RAINBOW TEDDY

---

## 一、工具说明

当前环境没有名为 `image2` 的独立插件入口，但可以使用内置图片生成能力生成 LOGO 概念图、品牌氛围图、包装视觉草案和PPT素材图。

建议工作流：

1. 使用图片生成能力生成 LOGO/VI 概念稿。
2. 从概念稿中筛选方向。
3. 将确认方向重绘为 SVG 矢量文件。
4. 提取品牌色、字体、图形元素，沉淀为VI规范。
5. 将可复用资产保存到 `品牌资产/` 下对应文件夹。

---

## 二、为什么不能只用图片稿当最终LOGO

AI生成图适合做视觉探索，但最终LOGO需要可复用、可缩放、可印刷、可上架平台使用。

| 文件类型 | 适合用途 | 是否适合作最终LOGO |
|----------|----------|-------------------|
| PNG/JPG图片稿 | 概念预览、PPT展示、风格探索 | 不建议作为最终源文件 |
| SVG矢量 | LOGO源文件、印刷、店招、平台图标 | 推荐 |
| PDF矢量 | 印刷、交付设计师 | 推荐 |
| 色板/字体规范 | 后续PPT、包装、店铺视觉调用 | 必须保存 |

## 四、建议先生成的LOGO方向

### 4.1 Teddy 主品牌

关键词：

- 泰迪熊
- 年轻
- 亲切
- 不尴尬
- 成人用品但不低俗
- 可爱但商业化

建议图形：

- 泰迪熊头像
- 圆润字标
- 温暖黄棕配色
- 可用于平台头像和包装贴纸

### 4.2 TEDDY TOGO

关键词：

- 低端店
- 即时零售
- 年轻、便利、活力
- 深夜便利店

建议图形：

- 站立泰迪
- 活力橙/黄色
- 更适合美团外卖头像和店铺头图

### 4.3 TEDDY BELLE

关键词：

- 高端女性
- 悦己
- 丝袜、内衣、精油
- 温柔、私密、仪式感

建议图形：

- 泰迪熊头像 + 丝带/蝴蝶结
- 玫瑰粉、香槟金、奶白
- 精致但不俗艳

### 4.4 RAINBOW TEDDY

关键词：

- LGBTQ友好
- 小众圈层
- 彩虹
- 包容、尊重、私密

建议图形：

- 泰迪熊 + 彩虹元素
- 不做过度刺激的SM视觉
- 适合私域和小众线上店

## 五、生成设置建议

| 项目 | 建议 |
|------|------|
| 输出用途 | LOGO概念稿、PPT素材、VI探索 |
| 图像风格 | vector-friendly logo concept |
| 背景 | 纯色浅背景，便于后续抠图和重绘 |
| 文字 | 尽量不要依赖AI生成准确文字，文字后期用矢量排版 |
| 色彩 | 使用项目品牌色体系 |
| 禁止 | 低俗、露骨、成人暗示过强、复杂渐变、过多细节 |
| 版本 | 每个方向先生成3-4个概念稿 |

---

## 六、后续执行步骤

1. 先生成主品牌 Teddy LOGO 概念稿。
2. 选定主品牌图形方向。
3. 再基于主品牌分别延展 TOGO、BELLE、RAINBOW。
4. 确认一个品牌色体系。
5. 生成并保存 `品牌色板.md`。
6. 生成并保存 `字体规范.md`。
7. 将最终确认LOGO重绘为SVG。

## 三、字体

| 场景 | 字体建议 | 备注 |
|------|----------|------|
| 英文 LOGO 重排 | Fredoka Bold / SemiBold | 圆润、亲和，适合 Teddy 系列 |
| 中文标题 | Noto Sans SC Bold | 免费开源路线，清晰稳定 |
| 中文正文 | Noto Sans SC Regular | PPT、说明、平台物料 |
| BELLE 高端标题 | Noto Serif SC SemiBold | 少量使用，增加精致感 |

## 四、平台头像规则

1. 四个 LOGO 均采用圆形构图，适合美团、饿了么、淘宝闪购头像裁切。
2. 平台头像内的主体狗头与品牌文字需要保持安全边距，避免被圆形裁切。
3. 小尺寸头像优先保证狗头识别，其次保证品牌名称。
4. 后续可以输出一版“无文字头像”，用于极小尺寸展示。

## 五、物料应用规则

| 物料 | 建议 |
|------|------|
| PPT | 公司主体 Teddy 做封面主标，三子品牌做商业模式页分栏 |
| 线上店铺 | 每个子品牌使用独立平台头像、独立主色和独立首图 |
| 配送袋贴纸 | Teddy 主体 LOGO + 子品牌色标签，可贴在统一配送袋上 |
| 门头 | 主体 Teddy 做实体店门头，三子品牌作为线上品牌矩阵展示 |
| 供应商材料 | 使用 Teddy 公司主体 LOGO，避免过早暴露全部子品牌策略 |

## 六、当前风险

1. 当前 LOGO 是 AI 图片概念稿，不是矢量商标文件。
2. 字体虽选择免费开源路线，但正式商用前仍建议复核授权页面并保存证据。
3. 平台页面模拟图只能用于 PPT 汇报，不应直接使用平台商标或高仿官方 UI。

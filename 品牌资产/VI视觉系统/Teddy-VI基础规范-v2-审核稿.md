## 三、字体规范

| 场景 | 字体建议 | 使用说明 |
|------|----------|----------|
| 英文标题/LOGO重排 | Fredoka Bold / SemiBold | 圆润、亲和，适合 Teddy 系列 |
| 中文标题 | Noto Sans SC Bold | 免费开源路线，清晰稳定 |
| 中文正文 | Noto Sans SC Regular | PPT、说明、平台物料正文 |
| BELLE 高级标题 | Noto Serif SC SemiBold | 少量使用，增强精致感 |

字体使用原则：

1. 优先使用免费、开源、可商用字体，降低侵权风险。
2. 正式商标注册、大规模投放或印刷前，需要保存字体授权页面截图。
3. LOGO 若后续做矢量化，文字部分建议用 Fredoka 或 Noto 系列重新排字。
4. PPT 对外发送时优先导出 PDF，避免接收方缺字体导致排版错乱。

## 四、LOGO 使用规则

1. 四个 LOGO 均采用圆形平台头像结构，适合美团、饿了么、淘宝闪购、公众号、抖音、小红书等头像场景。
2. 单独导出的四张 PNG 已处理为透明底，圆形外区域透明。
3. 平台头像小尺寸展示时，优先保证 Teddy 狗头像识别，其次保证品牌英文名识别。
4. 后续可补充“无文字头像版”，用于极小尺寸或社媒角标。
5. 旧版 LOGO 仅作历史追溯，不再作为当前主调用版本。

## 六、图片生成与保存规则

从 2026-06-10 起，Teddy 项目所有图片生成任务默认执行以下流程：

1. 生成图片前，先给用户提供至少三张或三套参考方向。
2. 用户确认方向后，才进入图片生成。
3. 图片生成后，先发给用户审核。
4. 只有用户明确回复“保存”“确认保存”或同等明确指令后，才保存到本地项目目录。
5. 未经用户确认，不主动把图片写入正式资产目录。
6. 当前 GitHub 自动同步已暂停，除非刘梓寒明确单独确认，不执行 `git push`。

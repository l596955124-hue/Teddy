## 七、统一文案口径

### 7.1 可以稳定使用的表达

| 场景 | 推荐表达 |
|------|----------|
| 品牌介绍 | Teddy 是一个年轻、有趣、不尴尬的成人用品即时零售品牌。 |
| 配送服务 | 同城即时配送，注重隐私包装与购买体验。 |
| 用户体验 | 让亲密用品购买变得更轻松、更自然。 |
| 高端线 | TEDDY BELLE 关注女性的私密仪式感与自我宠爱。 |
| 低端线 | TEDDY TOGO 提供高性价比、即时达的日常刚需选择。 |
| 小众线 | RAINBOW TEDDY 聚合更多元、有趣的小众品牌选择。 |

### 7.2 需要谨慎的表达

| 类型 | 处理原则 |
|------|----------|
| 医疗功效 | 不承诺治疗、改善疾病、增强功能等效果 |
| 过度露骨 | 避免直白露骨描述，平台文案优先生活化、场景化 |
| 低俗暗示 | 不使用低俗、擦边、挑逗性过强的标题 |
| 未成年人 | 明确仅面向成年人，避免学生化、校园化营销 |
| 绝对化承诺 | 不使用“最强、必备、100%有效”等绝对化表述 |

## 九、调用规则

1. 平台搭建、PPT、官网、公众号、抖音、小红书需要写品牌信息时，优先引用本文件。
2. 如果平台规则要求调整文案尺度，以平台专项中的审核规则为准，但品牌核心信息不随意改动。
3. LOGO、品牌色、字体、物料效果图需引用 `品牌资产` 下对应正式文件，不从聊天记录临时复制。
4. 本文件如发生关键变更，需要同步到 `项目总控上下文-精简版.md` 或跨工作流同步记录。
5. 任何新增子品牌、口号、账号名称、平台店名，都应先进入本表，再扩散到其它文件。

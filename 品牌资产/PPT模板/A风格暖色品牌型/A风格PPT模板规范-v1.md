# Teddy A风格PPT模板规范 v1

保存时间：2026-06-06

## 模板定位

A风格是 Teddy 品牌后续 PPT 的默认主模板，适用于：

- 商业计划书
- 内部执行汇报
- 选品汇报
- 月度经营复盘
- 品牌介绍
- 招商/合作沟通的初版材料

## 视觉关键词

- 温暖
- 干净
- 可爱但不幼稚
- 商业可信
- 即时零售感
- 隐私友好

## 品牌色

## 字体建议

优先使用免费或系统字体：

1. 中文：`Microsoft YaHei` / `Noto Sans SC`
2. 英文：`Aptos` / `Arial`
3. 可爱标题辅助：`Fredoka`，仅用于少量英文品牌字样

## 页面规则

1. 每页只表达一个核心观点。
2. 标题使用深咖啡色，尽量控制在一行。
3. 数据页使用大数字，不堆长段落。
4. 三品牌内容固定颜色：
   - TEDDY TOGO：活力橙
   - TEDDY BELLE：Belle粉
   - RAINBOW TEDDY：Rainbow紫
5. 成人用品相关内容不使用低俗、露骨、刺激性图片。
6. 所有平台和市场数据都加脚注，区分公开来源和内部测算。
7. 封面和章节页可以使用 image2 生成的暖色抽象背景。

## 标准页面类型

| 页面类型 | 用途 |
|----------|------|
| Cover | 封面 |
| Big Claim | 项目一句话/核心判断 |
| Evidence Metrics | 市场和财务数据 |
| Brand Matrix | 三品牌定位 |
| System Diagram | 一店三线上店模式 |
| Timeline | 90天执行计划 |
| Responsibility Matrix | 团队分工 |
| Risk Matrix | 风险应对 |
| Next Actions | 下一步任务 |

## 一、目录说明

| 文件夹 | 用途 |
|--------|------|
| `LOGO设计/` | 保存主品牌、子品牌、不同版本LOGO、源文件和导出图 |
| `VI视觉系统/` | 保存品牌VI规范、视觉应用、版式规范 |
| `品牌色与字体/` | 保存品牌色值、字体选择、可复用色板 |
| `可复用素材/` | 保存可反复调用的图标、插画、纹理、图片素材 |
| `包装与物料/` | 保存包装盒、隐私袋、卡片、贴纸、宣传物料 |
| `门店视觉/` | 保存招牌、灯箱、货架、陈列、装修视觉 |
| `线上店铺视觉/` | 保存美团、饿了么、淘宝、小程序等线上店铺视觉 |

---

## 二、使用原则

1. 可复用内容单独保存，不只写在聊天记录里。
2. 同一资产如果有多个版本，用版本号命名，例如 `TEDDY主Logo-v1.png`。
3. 品牌色、字体、LOGO源文件优先保存为可长期调用的规范文件。
4. 最终确认版本可以复制一份到 `输出文件/`。

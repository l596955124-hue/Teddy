# Teddy 线下门店与取货区视觉规范 v1 审核稿

更新时间：2026-06-10  
状态：用户确认方向后整理，作为后续门头、取货区、打包区、货架分区和 PPT 视觉生成的基础规范。

## 一、线下门店定位

Teddy 线下空间前期不按传统成人用品门店打造，而按“线上即时零售履约中心 + 私密护理到店咨询点”设计。

核心目标：

1. 服务美团、饿了么、淘宝闪购等线上订单的快速拣货、打包和骑手取货。
2. 承接私域客户到店自提、咨询和复购。
3. 支撑一个实体店同时承载 TEDDY TOGO、TEDDY BELLE、RAINBOW TEDDY 三个线上品牌。
4. 降低外部敏感度，方便选址、装修、平台审核和日常经营。

## 二、外部门头原则

外部门头只使用公司主体品牌 `TEDDY`，不直接展示三个子品牌，也不展示敏感品类。

### 推荐外部门头表达

- 主标识：TEDDY 主品牌 LOGO
- 可选副标题：私密护理 / 即时零售 / 生活补给
- 主色：暖金黄 `#F5A623`、奶油白 `#FFF8E8`
- 强调色：暖橘红 `#FF5A1F`
- 文字色：深可可棕 `#3B2416`

### 外部门头禁用表达

- 成人用品
- 情趣用品
- SM
- BDSM
- 同性恋专卖
- 性用品
- 低俗挑逗文案
- 真实平台 LOGO 或平台官方认证暗示

外部门头要像“友好、干净、可信的即时零售生活护理店”，不要像“强刺激成人用品店”。

## 三、橱窗与外部可见区域

前期建议橱窗保持克制，不做明显商品裸陈列。

推荐展示：

- Teddy 主品牌 LOGO
- 隐私包装说明
- 平台配送/到店自提提示
- 暖色灯光和基础品牌物料
- 可展示无敏感外观的礼盒、配送袋、感谢卡

不建议展示：

- 具体成人用品实物
- 暴露、挑逗或暗示过强的模特图
- SM/小众器具外露
- 大面积彩虹或小众表达直接对外暴露

## 四、内部空间分区

线下空间建议分为五个区域：

| 区域 | 功能 | 视觉重点 |
|------|------|----------|
| 前台/咨询区 | 到店咨询、自提、扫码加私域 | Teddy 主品牌，干净可信 |
| 打包区 | 订单复核、隐私包装、贴标 | 隐私包装流程清楚 |
| 待取货架 | 骑手取货、客户自提 | 编号清晰，不暴露商品 |
| 三品牌货架区 | TOGO/BELLE/RAINBOW 分区存放 | 用色区分，提升拣货效率 |
| 后仓补货区 | 库存、耗材、备货 | 内部管理优先，不对外展示 |

## 五、三品牌内部视觉分区

### TEDDY TOGO 快速补给区

定位：低价、刚需、快速、即时配送。

视觉建议：

- 主色：橙红 `#FF5A1F`
- 辅色：速度黄 `#FFC43D`
- 货架标签：橙白色
- 物料关键词：快、省、私密、深夜补给
- 陈列方式：按高频品、低价组合、深夜补给包分类

### TEDDY BELLE 女性悦己区

定位：女性、高端、卫生、舒适、礼盒感。

视觉建议：

- 点缀：香槟金 `#D4AF37`
- 货架标签：粉金色
- 物料关键词：舒适、卫生、宠爱自己、礼盒氛围
- 陈列方式：丝袜、服饰、女性护理、礼盒组合分区

### RAINBOW TEDDY 多元友好区

定位：多元、尊重、边界、小众探索。

视觉建议：

- 点缀：彩虹色、青绿 `#06D6A0`

- 物料关键词：多元、尊重、边界、私密探索

RAINBOW TEDDY 区域建议放在内部货架或咨询区内侧，不直接面对街面橱窗。

## 六、隐私取货与打包区

取货区是线下空间的核心，不是辅助。

### 标准流程

1. 接单
2. 拣货
3. 复核
4. 放入隐私包装
5. 贴封口贴和内部订单标签
6. 放入待取货架
7. 骑手或客户取货

### 必备物料

- 白色隐私配送袋
- 牛皮纸盒
- Teddy 通用封口贴
- 售后说明卡
- 感谢卡
- 内部分拣贴纸
- 待取货编号标签
- 骑手取货提示牌

### 打包区视觉提示

推荐文字：

- 默认隐私包装
- 外观不展示商品信息
- 平台售后
- 成年人限定
- 可先咨询再选择

不建议文字：

- 情趣用品专送
- SM 专区
- 成人刺激用品
- 任何暴露具体敏感品类的外显提示

## 七、货架标签系统

货架标签以“内部识别 + 快速拣货”为目标，不做过度装饰。

建议标签结构：

- 品牌色条
- 子品牌英文名
- 类目中文名
- 内部类目编号
- SKU 数量或补货提示

示例：

| 品牌 | 标签示例 |
|------|----------|
| TEDDY TOGO | TOGO-01 日常刚需 |
| TEDDY TOGO | TOGO-02 深夜补给 |
| TEDDY BELLE | BELLE-01 女性悦己 |
| TEDDY BELLE | BELLE-02 丝袜/服饰 |
| RAINBOW TEDDY | RAINBOW-01 彩虹友好 |
| RAINBOW TEDDY | RAINBOW-02 边界意识 |

## 八、到店客户动线

### 私域客户到店

1. 客户到店
2. 前台确认需求
3. 需要咨询则引导到咨询区
4. 需要自提则从待取货架取包
5. 尽量不让客户直接进入后仓

### 骑手取货

1. 骑手到店
2. 查看待取货架编号
3. 前台核对订单尾号
4. 交付隐私包裹
5. 不展示商品信息

商业计划书中可用一页展示线下空间逻辑：

- 左侧：外部门头，Teddy 主品牌克制露出

- 右侧：内部三品牌分区，体现线上三店共用一个实体履约中心

这一页的核心论点：

> 一个低成本实体空间，同时支撑三家线上店、统一履约、私密交付、私域承接和品牌体验。

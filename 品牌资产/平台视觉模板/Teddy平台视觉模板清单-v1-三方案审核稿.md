## 一、图片生成前审核规则

从本节点开始，Teddy 项目所有需要生成图片的任务，先执行以下流程：

1. 先输出至少 3 个审核稿方向，命名为 A / B / C。
2. 每个审核稿必须包含：风格定位、主色、构图、核心文案、适用平台、适用品牌、合规风险。
3. 用户确认某一稿，或确认“混合 A+B/C”后，才进入图片生成。
4. 生成图片后必须保存到 `D:\Teddy创业项目\品牌资产\` 对应目录，并同步阶段存档。
5. 正式用于平台上线前，必须由平台入驻专项复核最新平台尺寸、审核规则和敏感词。

## 三、三套视觉审核稿

### 审核稿 A：即时零售高转化版

| 项目 | 内容 |
|------|------|
| 核心定位 | 像外卖便利店一样清楚、快、直接，第一眼知道可以马上买。 |
| 主适用品牌 | TEDDY TOGO，兼容美团/淘宝闪购首店。 |
| 适用平台 | 美团、淘宝闪购、抖音短视频封面、开业活动横幅。 |
| 主色 | 外卖橙 `#FF5A1F` + 速度黄 `#FFC43D` + 深可可棕 `#3B2416`。 |
| 画面感觉 | 明亮、干净、有速度感，强调按钮感、标签感和即时配送。 |
| 构图 | 左侧/上方放子品牌头像，主文案大字居中，右侧用配送袋、闪电、订单卡片、简化商品盒做氛围。 |
| 主文案 | 你的深夜亲密补给站 |
| 辅助文案 | 快速响应 / 隐私包装 / 日常刚需 |
| 平台优势 | 适合转化，适合用户扫一眼理解服务。 |
| 风险点 | 可能显得偏低端，需要在排版和留白上避免廉价促销感。 |

### 审核稿 B：女性高端情绪价值版

| 项目 | 内容 |
|------|------|
| 核心定位 | 让女性用户感到干净、舒服、被认真对待，强调质量、卫生、包装和氛围。 |

| 适用平台 | 小红书、官网、公众号、PPT高端店页面、BELLE平台头图。 |

| 辅助文案 | 质量 / 卫生 / 舒适 / 氛围 |
| 平台优势 | 适合女性悦己、小红书种草、官网品牌感。 |

## 四、推荐采用方式

不建议三家店用同一视觉风格。建议采用“三品牌分层统一”的方式：

| 品牌 | 推荐审核稿 | 说明 |
|------|------------|------|
| TEDDY 主品牌 | A+B 混合 | 保留 Teddy 暖黄亲和感，同时增加品牌质感。 |
| TEDDY TOGO | A | 强调即时零售、深夜补给、低端走量。 |
| TEDDY BELLE | B | 强调女性高端、质量卫生、舒适和情绪价值。 |
| RAINBOW TEDDY | C | 强调多元圈层、彩虹友好、BDSM/SM探索边界。 |
